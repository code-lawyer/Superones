# Vault2077 一次性 OPC 服务产品文档

## 1. 文件夹用途

本文件夹定义六项一次性 OPC 标准服务的完整业务合同、交付链路和运营规范。它们面向中国大陆境内、以上海为主要交付地区的超级个体与一人公司。

这些文件是**待业务、法律、财税和履约能力共同确认的产品草案**。未同步进入 [`docs/Vault2077-OPC-Service-Catalog.md`](../docs/Vault2077-OPC-Service-Catalog.md)、后台 OPC 菜单并通过发布校验前，不构成已经公开销售的服务承诺。

## 3. 统一产品原则

### 3.1 售卖结果，不售卖政府动作

政府免费办理的事项必须明确写“官方收费 0 元”或“官方规则未列收费项目”。Vault2077 收取的是专业判断、材料组织、流程编排、进度管理、成果检查和证据归档的服务费，不得把服务费称为政府规费。

### 3.2 先准入，再履约

所有产品先执行准入问卷和范围确认。出现强监管行业、重大争议、境外主体、复杂数据跨境、自研大模型、多人股权安排或其他超范围事实时，停止进入标准链路，提供退回、改签或个案升级路径。

### 3.3 不承诺主管机关或平台结果

Vault2077 可以承诺按确认事实完成材料、提交、跟进和补正，但不承诺营业执照、备案、许可、商标、软件登记、应用商店或其他外部审查必然通过。

### 3.4 一项服务只有一个主要验收结果

产品可以编排多个步骤，但必须围绕一个最终状态验收。不得把不相关事项拼成折扣套餐，也不得把持续代账、年度维护、云资源订阅或长期顾问服务混入一次性交付。

## 4. 统一费用结构

每份报价和订单快照必须分别列出：

| 费用层 | 定义 | 处理方式 |
| --- | --- | --- |
| Vault2077 服务费 | 专业判断、材料、填报、协调、检查和归档 | 固定含税价格 |
| 官方收费 | 政府机关明确的规费或“0 元/未列收费项目” | 原额列示，不加价 |
| 第三方必要成本 | 银行产品、地址、云资源、域名、平台账号、检测测评等 | 用户直接支付或书面确认代付 |
| 超范围服务 | 新增主体、产品、人员、版本、补正或整改 | 变更单确认后执行 |

报价必须注明是否含税、官方收费证据、第三方费用承担人和退款条件。不得把“官方未列收费项目”擅自改写为“官方报价 0 元”。

## 5. 统一计时规则

- “材料齐备”是内部周期起算点，必须由运营人员书面确认。
- 因用户未提供材料、未完成签署、未支付第三方费用或未授权必要账号而等待时，暂停计时。
- 因主管部门、接入服务商、银行、应用商店或其他第三方审核而等待时，暂停内部计时并单独记录外部状态。
- 用户超过 10 个工作日未响应，订单进入“等待用户”；超过 30 个自然日仍未恢复，可按阶段结算并关闭。
- 法规、平台规则或用户业务事实发生变化时，重新执行适用性判断；超出原范围的，通过变更单处理。

## 6. 统一补正和变更规则

- 固定价格默认包含两轮集中修改；主管机关或平台针对原申报事实提出的一轮标准补正包含在内。
- 用户改变主体、品牌、域名、产品版本、数据处理、模型、人员关系或经营模式，不属于修改，属于范围变更。
- 因 Vault2077 错漏产生的修正不占用户修改轮次。
- 超范围工作未取得书面变更确认前不得开始，也不得先做后收费。

## 7. 统一终止与退款框架

退款按已完成阶段结算，不按“是否最终获批”结算：

| 状态 | 建议处理 |
| --- | --- |
| 准入前且尚未开展实质工作 | 退还全部服务费 |
| 准入判断完成但尚未制作核心材料 | 扣除产品价格的 15% |
| 核心方案和材料已形成但尚未提交 | 累计结算至 50% |
| 已提交主管部门、平台或已交付核心文件 | 累计结算至 80% |
| 已完成验收成果或进入最终外部等待 | 服务费不退，继续完成约定跟进 |

因 Vault2077 无法履行、错误准入或重大交付缺陷导致终止的，不适用上述扣费比例，应按未履行部分退款并完成必要资料交接。正式发布前须由法律和财务人员确认退款文案及发票处理。

## 8. 统一数据与账号边界

- 只收集完成服务所必需的主体、人员、产品和联系信息。
- 用户密码、短信验证码、私钥和支付密码原则上由用户本人操作；确需临时授权时采用可撤销、可审计方式，不以明文长期保存。
- 身份证件、合同、人员信息、源代码和账号资料使用受控存储，不进入公开内容或跨区域公开任务。
- 服务完成后交付成果目录和材料清单；订单联系方式按全站保留策略处理，其他业务材料的保留期限在具体产品中说明。

## 9. 每份文档的完整性要求

每项产品必须同时定义：

1. 产品卡和一句话结果；
2. 适用对象、准入条件和拒绝条件；
3. 包含项与明确排除项；
4. 用户材料和材料齐备标准；
5. 分阶段交付链路和阶段门；
6. 交付成果、格式和验收标准；
7. 服务费、官方收费和第三方费用；
8. 周期、暂停、补正、变更和退款规则；
9. 异常、升级和外部顾问转交条件；
10. 运营 SOP、沟通节点、数据归档和质量指标；
11. 依据、假设、版本和复查日期。
