# 企业官网合规上线

## 1. 产品卡

| 字段 | 内容 |
| --- | --- |
| 产品编号 | `OPC-ONCE-002` |
| 产品类型 | 专项服务 / 一次性交付 |
| 一句话结果 | 让一个普通企业展示官网完成备案、公示和基础隐私检查，形成可核验的合规上线证据包 |
| 标准服务费 | 人民币 3,800 元，含税 |
| 标准内部周期 | 材料齐备后 5–7 个工作日；接入商、通信管理局和公安机关等待时间另计 |
| 标准容量 | 一个中国大陆主体、一个域名、一个网站、一个主要版本、最多 10 个主要页面 |
| 现有目录关系 | 从 `I-04 线上经营与平台准入` 和 `S-06-03 数字产品上线合规包` 中拆出的窄范围服务 |

## 2. 最终结果

产品验收时，用户应当能够回答并证明：

- 网站为什么只需备案，或者为什么必须升级到许可判断；
- ICP备案、公网安备和网站页脚公示分别处于什么状态；
- 网站实际收集哪些联系信息，隐私文本是否与表单一致；
- 主体、域名、接入商和网站负责人的信息是否一致；
- 哪些事项已经完成，哪些是用户、开发者或外部机构的后续责任。

本产品不出售“备案号”，也不保证主管部门通过；它交付正确分流、完整材料、过程记录和上线检查。

## 3. 标准准入

### 3.1 标准版本必须同时满足

- 网站主要用于展示企业、品牌、产品、案例和联系方式；
- 不为第三方商家提供交易撮合、店铺或在线交易处理平台；
- 不提供新闻、出版、视听、医疗、金融、教育等需专项许可的服务；
- 不包含用户发帖、评论、直播、论坛、公众账号平台等舆论表达功能；
- 不包含面向公众的生成式 AI、个性化推荐或复杂算法服务；
- 最多包含普通联系表单、订阅表单或商务咨询入口；
- 已有或准备购买中国大陆接入资源，并能配合接入商核验。

### 3.2 触发升级

- 有付费会员、在线内容销售、SaaS、互联网信息收费或平台抽佣；
- 有第三方商家、用户交易、撮合、竞价、榜单、推荐或UGC；
- 处理身份证、金融账户、精确位置、健康等敏感个人信息；
- 网站同时承担 App 后端、开放 API 或公众 AI 功能；
- 网站主体、域名持有人、服务器和实际经营者无法一致解释；
- 涉及特殊行业许可、数据跨境或网络安全等级保护专项要求。

升级后可改签数字产品合规、App合规、AI应用合规、ICP/EDI个案或外部专业服务；未确认升级前不继续申报。

### 3.3 不适用

- 没有网站、只使用第三方平台主页或纯线下经营；
- 只需要购买域名、服务器或网站开发；
- 试图通过境外服务器规避对境内业务的适用性判断；
- 要求使用虚假主体、虚构负责人或借用他人备案。

## 4. 服务范围

### 4.1 包含

1. 一次网站业务和资质适用性问卷；
2. ICP备案、ICP许可证、EDI、APP备案、公网安备和特殊许可分流；
3. 主体、域名、接入资源、网站负责人和联系方式一致性核验；
4. 一个网站的 ICP 备案材料组织、接入商提交协调和一轮标准补正；
5. 网站正式联通后的公网安备材料组织和提交指导；
6. 网站名称、主体信息、联系方式、备案号和公安备案号公示检查；
7. 一个普通联系表单的数据字段和最小必要检查；
8. 一份适配实际功能的简版隐私声明或现有文本修订；
9. 最多 10 个主要页面的桌面端合规检查；
10. 最终官网合规上线证据包。

### 4.2 不包含

- 域名、服务器、CDN、SSL、企业邮箱和云资源费用；
- 网站设计、开发、部署、性能、安全加固或长期运维；
- ICP许可证、EDI许可证、APP备案、算法备案或生成式 AI 应用登记；
- 网络安全等级保护定级、备案、测评或整改；
- 复杂用户协议、交易规则、退款规则、Cookie管理平台或跨境隐私方案；
- 网站内容事实核查、广告审查、商标检索或图片字体授权清理；
- 接入商、主管部门或公安机关要求的现场核验及第三方检测。

## 5. 用户材料

| 材料组 | 内容 | 齐备标准 |
| --- | --- | --- |
| 主体 | 营业执照、法定代表人和网站负责人信息 | 证件有效、人员可配合核验 |
| 域名 | 域名证书、注册商、持有人、解析计划 | 持有人与备案主体关系可解释 |
| 接入 | 服务器/云厂商账号、接入地区、IP和接入商 | 已取得接入资源或有明确采购计划 |
| 网站 | 测试地址、页面清单、网站名称、功能说明 | 可实际访问或提供完整原型 |
| 数据 | 表单字段、邮件订阅、Cookie、统计和外部脚本清单 | 与当前主要版本一致 |
| 公示 | 企业名称、地址、电话、邮箱、客服和投诉方式 | 已确认公开口径 |
| 既有状态 | 已有ICP备案、公网安备、许可或历史退件 | 回执和原因完整提供 |

用户或其开发者必须具备修改 DNS、网站页脚和隐私文本的能力；未授权开发改动时，Vault2077只交付整改指令和复核，不代为开发。

## 6. 交付链路

| 阶段 | 动作 | 输出 | 阶段门 | 内部目标时间 |
| --- | --- | --- | --- | ---: |
| 0. 业务分流 | 审查网站功能、收费、第三方和行业属性 | 《网站准入与资质分流单》 | 确认为普通官网 | 1 个工作日 |
| 1. 资产核验 | 核验主体、域名、接入和负责人一致性 | 《备案资产核验表》 | 无阻断性不一致 | 1 个工作日 |
| 2. ICP备案 | 组织材料、协调接入商提交和标准补正 | 提交记录、回执和ICP备案结果 | 取得结果或形成升级记录 | 1–2 个工作日，不含外部等待 |
| 3. 网站上线 | 用户/开发者完成解析、SSL和内容上线 | 上线版本地址和版本快照 | 网站可公开访问 | 用户动作，不计时 |
| 4. 公网安备 | 组织正式联网后的公安备案材料和提交 | 提交记录及公安备案结果 | 状态明确 | 1 个工作日，不含外部等待 |
| 5. 页面检查 | 核对公示、联系表单、隐私文本和备案号链接 | 《官网上线检查表》 | 阻断项清零 | 1–2 个工作日 |
| 6. 验收归档 | 汇总结果、截图、回执、缺口和复查触发条件 | 《官网合规上线证据包》 | 用户确认或提交一次缺陷清单 | 1 个工作日 |

## 8. 验收标准

- 网站业务被确认属于标准范围，或已经书面升级；
- ICP备案和公网安备均有结果、回执或明确的外部等待状态；
- 页脚正确展示主体名称、ICP备案号及链接、公安备案号及链接；
- 联系表单字段与隐私声明一致，不存在已识别的非必要字段；
- 主要页面不存在错误主体、虚假许可或明显缺失的联系方式；
- 所有阻断项均完成，非阻断项有责任人和截止日期；
- 用户收到可核验的备案、公示、截图和版本记录。

外部备案尚在等待但Vault2077内部工作已完成时，订单可进入“外部等待”，不提前标为最终完成；收到结果后补齐证据包。

## 9. 价格与第三方费用

| 项目 | 费用口径 |
| --- | ---: |
| Vault2077 含税服务费 | ¥3,800 |
| ICP备案官方收费 | 上海官方 0 元，未指定收费代理 |
| 公网安备官方收费 | 上海官方 0 元、中介服务“无” |
| 域名 | 用户直接向注册商支付 |
| 服务器、CDN、SSL、邮箱 | 用户直接向服务商支付 |
| 网站开发和整改 | 不包含，另行向开发者采购 |

市场上数百元的ICP备案或公网安备“代办费”是可选材料服务费，不是政府收费。本产品价格包含更前置的适用性判断、页面检查和最终证据归档。

## 10. 周期与暂停

- 接入商初审、通信管理局审核和公安机关处理均属于外部等待；
- 域名实名认证、主体信息同步或服务器购买未完成时暂停；
- 网站未正式联通前不能完成公网安备阶段；
- 用户开发者未按清单修改页脚、表单或隐私文本时暂停验收；
- 网站新增交易、UGC、AI或敏感信息功能时重新准入。

## 11. 修改、变更与退款

- 包含两轮集中页面和文本修改、一轮标准备案补正；
- 更换主体、域名、接入商或网站负责人属于范围变更；
- 新增第二个域名、第二个网站或第二种语言版本需另行报价；
- 已提交备案后因用户改变网站业务导致撤回，按已完成阶段结算；
- 因Vault2077错误分流或材料错误产生的补正和重做不占用户轮次。

建议阶段结算比例：准入15%、资产核验30%、ICP备案提交55%、公网安备提交75%、证据包100%。

## 12. 异常升级

遇到以下情况必须暂停并升级：

- 接入商或主管部门判断属于经营性互联网信息服务；
- 网站实际承担第三方平台、交易撮合或在线数据处理；
- 发现公众AI、算法推荐、UGC、直播或评论功能；
- 涉及医疗、金融、教育、新闻、出版、视听等行业；
- 表单或脚本处理敏感个人信息、未成年人信息或数据出境；
- 主体、域名、服务器和实际经营关系无法合理解释。

## 13. 运营 SOP

1. 核验订单和付款，发送网站业务问卷；
2. 由合规人员完成资质分流，开发人员不得自行判断许可；
3. 校验域名、主体、接入和负责人材料；
4. 通过接入商路径提交ICP备案，保存所有回执；
5. 提醒用户备案期间不得擅自改变申报事实；
6. 上线后通过正式网址逐页检查，并发起公网安备；
7. 用隐私字段表核对表单、统计和第三方脚本；
8. 检查页脚链接和备案号，保存带日期截图；
9. 第二人复核资质分流、备案号和最终报告；
10. 交付证据包，记录复查触发条件并完成订单。

## 14. 数据和账号边界

- 域名、云账号和网站后台由用户掌握；Vault2077原则上不保存密码。
- 短信验证码、实名核验和接入商人脸识别由用户本人完成。
- 网站提交的客户信息不得作为演示或测试数据带出用户环境。
- 页面截图如包含真实联系人、订单或客户内容，交付前必须脱敏。

## 15. 交付后复查触发条件

出现以下变化时，原验收结论失效或需要复查：

- 更换主体、域名、服务器、接入商或网站负责人；
- 新增收费、交易、用户账户、评论、直播、AI或推荐功能；
- 新增敏感个人信息、第三方SDK或境外数据接收方；
- 备案信息、联系方式、公司名称或地址变化；
- 主管部门、接入商或平台规则发生实质变化。

## 16. 质量指标

- 标准范围内首次分流准确率；
- 因材料问题被接入商退回的比例；
- 页面检查阻断项平均数量和关闭周期；
- 备案号、链接和主体公示错误率，目标为0；
- 交付后30日内发现的未披露功能比例。

## 18. 发布门槛

- 已准备网站业务问卷、资质分流表、资产核验表和页面检查表；
- 已与至少一家主流接入商完成真实流程演练；
- 已验证ICP备案与公网安备的官方0元口径；
- 已确定备案等待、退件和升级的客户沟通模板；
- 已明确开发整改不包含，并准备可交给开发者的整改清单格式；
- 已在OPC菜单中以独立SKU发布，不再隐藏在宽泛的“线上经营”套餐中。
