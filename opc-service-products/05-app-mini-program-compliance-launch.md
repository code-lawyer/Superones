# App 或小程序合规上线

## 1. 产品卡

| 字段 | 内容 |
| --- | --- |
| 产品编号 | `OPC-ONCE-005` |
| 产品类型 | 基础设施 / 一次性交付 |
| 一句话结果 | 让一个App或小程序的备案、隐私、权限、SDK、公示和平台材料达到可检查的上线状态 |
| 标准服务费 | 人民币 9,800 元，含税 |
| 标准内部周期 | 材料齐备后 10–15 个工作日；接入商、分发平台和主管部门等待时间另计 |
| 标准容量 | 一个App或一个小程序、一个主体、一个主要版本、一个主要市场、最多20个主要页面、15个SDK、30项个人信息字段 |
| 现有目录关系 | 从 `I-04`、`I-07` 与 `S-06-03` 中拆出的可验收产品 |

“App或小程序”表示一次订单选择其中一条路线，不同时覆盖两个产品形态。Android和iOS若功能、SDK和数据处理实质相同，可作为同一App主要版本；存在重大差异时另行评估。

## 2. 最终结果

服务结束时，用户获得一个“上线证据包”，能够证明：

- 产品是否需要APP/小程序备案、ICP/EDI许可、公安备案、等保或AI专项判断；
- 当前版本收集的个人信息、系统权限和第三方SDK已经盘点；
- 隐私政策、用户协议、权限弹窗和产品实际行为可以相互对应；
- 备案、公示和平台提交材料已经完成或处于可解释的外部等待；
- 阻断上线的问题、非阻断整改和后续复查条件已经分级。

本产品不承诺应用商店或小程序平台必然审核通过，也不代替软件开发和安全测试。

## 3. 标准准入

### 3.1 可以进入

- 一个已经可演示的App或小程序主要版本；
- 主体、域名、接入资源、签名/包名或小程序主体可核验；
- 主要服务对象位于中国大陆；
- 不属于金融、医疗、未成年人核心服务、新闻出版等强监管行业；
- 不运营第三方商家平台或复杂交易撮合；
- 不自研、训练或微调面向公众的大模型；
- 不包含公众生成式AI功能，或者相关AI功能在本订单中明确关闭并单独进入AI产品；
- 个人信息、SDK和页面数量不超过标准容量；
- 用户可以安排开发者执行必要整改。

### 3.2 必须升级

- 处理生物识别、健康、金融账户、精确轨迹、大量未成年人信息；
- SDK超过15个、个人信息字段超过30项或多端行为明显不同；
- 提供公众AI、算法推荐、直播、UGC、社交、即时通信或内容平台；
- 涉及第三方商家、平台交易、分账、在线支付清算或增值电信许可；
- 数据出境、境外团队远程访问或境外SDK处理个人信息；
- 定级为二级以上系统并需等保备案，或客户要求测评；
- 已被平台拒审、通报、下架或收到监管整改要求。

### 3.3 不适用

- 只有概念稿，尚无可检查的产品版本；
- 只需要开发、上架截图或软著代办；
- 要求复制他人隐私政策或隐瞒SDK、权限和真实数据行为；
- 同时要求多个小程序、多个独立App或多个国家/地区上线。

## 4. 服务范围

### 4.1 共同包含项

1. 产品、业务、收费、平台、行业和数据适用性问卷；
2. APP/小程序备案、ICP/EDI、公安、等保和AI事项分流；
3. 主体、域名、包名/签名、小程序主体和接入资源核验；
4. 一个主要版本的用户旅程和页面清单；
5. 不超过30项个人信息字段的数据清单；
6. 不超过15个第三方SDK/服务的用途和披露清单；
7. 系统权限、调用时机、拒绝路径和最小必要检查；
8. 一份隐私政策、一份用户协议及必要的第三方共享清单；
9. APP或小程序备案材料组织、提交协调和一轮标准补正；
10. 平台隐私标签、权限说明、客服和投诉材料清单；
11. 最多20个主要页面的一轮上线检查；
12. 最终上线合规报告和证据包。

### 4.2 App路线特有项

- 包名、签名、应用名称、分发平台和服务器信息核验；
- APP备案主体和接入信息材料；
- Android/iOS隐私标签及权限说明检查；
- 一个主要应用商店版本的材料清单。

### 4.3 小程序路线特有项

- 小程序主体、管理员、服务类目和域名核验；
- 小程序备案和平台隐私保护指引检查；
- 一个主要平台的类目、隐私、客服和版本材料清单。

### 4.4 不包含

- UI/UX、产品设计、代码开发、SDK替换或权限整改；
- 应用商店账号、开发者账号、软著、签名证书、云资源和域名费用；
- ICP/EDI经营许可、算法备案、AI应用登记、等保备案/测评；
- 渗透测试、漏洞修复、代码审计或隐私合规认证；
- 正式个人信息保护影响评估、数据出境评估或安全事件处置；
- 特殊行业许可、平台申诉、拒审争议或已下架产品恢复；
- 多语言、多国家或多个独立版本。

## 5. 用户材料

| 材料组 | 内容 | 齐备标准 |
| --- | --- | --- |
| 主体与账号 | 营业执照、管理员、开发者账号、平台主体 | 主体和管理员可完成实名核验 |
| 产品版本 | 安装包/体验版、页面清单、版本号、功能说明 | 可完整走通主要用户旅程 |
| 技术标识 | 域名、服务器、包名、签名、小程序ID、API清单 | 与拟提交版本一致 |
| 数据 | 字段、用途、来源、保存期限、共享和删除方式 | 不超过30项并可对应页面 |
| SDK | SDK名称、提供方、版本、用途、数据和链接 | 不超过15个且来源可核验 |
| 权限 | 相机、相册、位置、通讯录、通知等调用场景 | 说明调用时机和拒绝后路径 |
| 商业规则 | 价格、订阅、自动续费、退款、客服和投诉 | 与实际界面一致 |
| 既有文本 | 隐私政策、用户协议、平台标签、退件记录 | 提供当前线上/拟上线版本 |

开发者应配合提供真实技术行为；只提供产品经理口头描述不能视为材料齐备。

## 6. 交付链路

| 阶段 | 动作 | 输出 | 阶段门 | 内部目标时间 |
| --- | --- | --- | --- | ---: |
| 0. 准入分流 | 审查行业、交易、AI、数据、平台和历史风险 | 《产品准入与资质分流单》 | 标准范围通过 | 1日 |
| 1. 版本冻结 | 确认主体、版本、包名/ID、页面和主要市场 | 《合规检查版本确认书》 | 检查对象固定 | 1日 |
| 2. 数据盘点 | 建立用户旅程、字段、SDK、权限和外部处理方清单 | 《数据与第三方处理总表》 | 关键行为无未知项 | 2–3日 |
| 3. 文本与界面 | 修订隐私、协议、共享清单、权限和平台标签 | 第一版合规文件包 | 文本与真实行为一致 | 2–3日 |
| 4. 备案提交 | 组织APP/小程序备案及一轮标准补正 | 材料、回执和状态记录 | 已提交或形成升级结论 | 1–2日，不含外部等待 |
| 5. 整改复核 | 检查开发整改和最多20个主要页面 | 《上线阻断与整改清单》 | 阻断项清零 | 2–3日，用户整改暂停 |
| 6. 平台材料 | 核对类目、隐私标签、客服、权限和版本说明 | 《平台提交材料清单》 | 材料可提交 | 1日 |
| 7. 验收归档 | 汇总备案、文本、检查和证据 | 《App/小程序合规上线报告》 | 用户确认 | 1日 |

## 8. 验收标准

- 唯一主体、产品形态、版本、市场和主要用户旅程已经冻结；
- APP/小程序备案有提交结果、回执或明确的外部等待状态；
- 个人信息字段、SDK、系统权限和外部处理方均有用途和责任人；
- 隐私政策、用户协议、平台标签和实际产品行为可以逐项对应；
- 已识别的上线阻断项清零，非阻断项有责任人和截止日期；
- 客服、投诉、账号注销、权限拒绝和个人权利路径可实际操作；
- 平台提交材料达到可提交状态；
- 用户收到完整文件、截图和版本证据。

平台最终上架或主管部门最终审核不作为无条件验收承诺；因本产品材料错误产生的退件应免费修正。

## 9. 价格与费用

| 项目 | 口径 |
| --- | ---: |
| Vault2077 含税服务费 | ¥9,800 |
| APP/小程序备案官方收费 | 官方办理 0 元 |
| 开发者账号、应用商店、签名证书 | 用户承担 |
| 域名、服务器、短信、推送和SDK | 用户承担 |
| 代码整改、安全测试和许可申请 | 不包含 |
| 软件著作权 | 非开业必办；需要时另购或自行办理 |

服务费不能写成“APP备案费9,800元”。产品价值是数据盘点、协议、界面、备案编排、整改复核和上线证据。

## 10. 周期和暂停

- 接入商、分发平台、通信管理局和应用商店处理时间不计入内部周期；
- 产品版本不可访问、开发者未提交技术清单或主体未完成实名时暂停；
- 需要开发整改时，从发出清单至用户提交新版本期间暂停；
- 用户在检查期间新增SDK、权限、支付、AI或社交功能时重新准入；
- 外部规则变化导致新增材料时，先判断是否仍在原范围。

## 11. 修改、变更与退款

- 包含两轮集中文本/界面意见和一轮标准备案补正；
- 同一App的普通版本号更新属于修改；重大用户旅程或数据处理变化属于变更；
- App改为小程序、增加第二个平台或新增独立管理后台属于新范围；
- 用户拒绝执行阻断性整改时，可交付“未就绪报告”并按阶段结算；
- 因Vault2077错误遗漏SDK、字段或权限而造成退件，免费重做对应部分。

建议阶段结算：准入15%、版本与数据盘点35%、文件包60%、备案提交75%、整改复核90%、最终报告100%。

## 12. 异常升级

必须升级的典型情况：

- 出现公众AI、算法推荐、UGC、直播、社交或即时通信；
- 处理敏感个人信息、未成年人信息或数据出境；
- 平台交易、分账、第三方商家或经营性互联网信息服务；
- 主管部门或客户要求等保备案、测评或其他安全认证；
- 已收到监管整改、平台下架或批量用户投诉；
- 实际SDK行为与开发者提供的说明不一致。

## 13. 运营 SOP

1. 核验订单，发送业务、版本、数据、SDK和权限问卷；
2. 合规人员完成资质分流，产品或开发人员不得自行豁免许可；
3. 与用户冻结唯一检查版本并保存哈希、版本号或平台构建号；
4. 逐条建立数据、SDK、权限和页面映射；
5. 文本编写必须来自真实行为，不复制其他产品模板后直接交付；
6. 通过接入商或平台路径提交备案并保存回执；
7. 用真实设备或体验环境复核主要旅程、权限拒绝和注销路径；
8. 阻断项关闭后形成平台材料，不替用户伪造截图或测试账号；
9. 第二人复核数据清单、文本、备案主体和最终报告；
10. 交付证据包，撤销临时测试账号和访问权限。

## 14. 数据和测试边界

- 测试优先使用专用测试数据，不使用真实客户或员工信息；
- 不保存应用商店密码、签名私钥、短信验证码和生产密钥；
- 需要检查SDK网络行为时应在用户授权环境进行，并明确工具和数据范围；
- 截图、日志和网络记录交付前必须删除令牌、手机号、身份证和其他不必要信息；
- 完成后撤销测试账号、后台和云平台临时权限。

## 15. 交付后复查触发条件

- 新增SDK、权限、个人信息字段、用户旅程或处理目的；
- 新增订阅、自动续费、支付、第三方交易或广告；
- 新增AI、推荐、UGC、社交、直播或未成年人功能；
- 更换主体、域名、包名、签名、小程序ID、服务器或主要市场；
- 发生安全事件、平台拒审、下架或监管问询。

## 16. 质量指标

- 数据字段、SDK和权限未知项数量，目标为0；
- 因材料错误产生的备案退件率；
- 阻断项关闭周期；
- 文本与真实产品行为不一致数量；
- 平台首次提交的材料完整率；
- 临时账号和访问权限撤销率，目标为100%。

## 18. 发布门槛

- App路线和小程序路线各完成至少一个模拟全链路；
- 具备数据、SDK、权限、平台标签和页面检查模板；
- 已确定AI、敏感信息、跨境、平台交易和等保事项的升级路径；
- 有真实开发者可以承接整改，但公开页面不将开发默认包含；
- 已验证备案官方0元和第三方平台费用口径；
- 公开页面明确一次订单只覆盖一个App或一个小程序。
