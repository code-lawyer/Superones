# Frontier 采用境内 GitHub 快速路径与异步回退

Frontier 的报名、挑战验证和参赛仓库观察取决于当前参赛名单，需要在用户操作后快速反馈并持续形成一致排名。境内业务服务因此可以使用服务端凭证直接读取已知公开 GitHub 仓库：交互式核验优先即时执行，每小时观察由境内后台按当前已验证名单运行；普通页面和浏览器只读取境内状态与最近成功快照，不直接请求 GitHub。

境内直读是快速路径，不是唯一成功路径。请求必须有短超时、限流、缓存/条件请求和可审计来源；暂时不可达时，报名保持待验证、榜单保留上一成功值，并把只含公开仓库标识的任务交给统一境外采集器重试，结果通过 `rankings` 通道签名回传。邮箱、奖品资料和后台备注不得进入 GitHub 请求、公开任务或境外采集产物。此例外不改变其他频道统一境外采集、境内处理和单一正式写模型的原则。
