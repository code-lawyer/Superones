# ADR-0016：游骑兵公开头像媒体存储

## 决策

生产环境使用与应用同地域的阿里云 OSS Standard LRS 保存服务端处理后的公开游骑兵头像；本地开发使用独立磁盘目录适配器。RDS 目录状态只保存不可变对象 key、SHA-256、尺寸、schema 版本和更新时间，不保存原图、Base64 图片或 OSS 凭证。

每次上传在受保护后台经服务端解码，校验 JPEG/PNG/WEBP、5MB 上限、最小 320×320 和像素总量，自动按方向旋转、去除元数据并生成 320×320 与 800×800 两份 WebP。对象 key 包含游骑兵 slug 和处理结果哈希；替换创建新 key，不覆盖旧 key。发布目录前对两份对象执行 HEAD，并校验对象 SHA-256 元数据。

公开页面通过独立媒体域名读取处理后对象；目录缩略图懒加载 320 版本，详情读取 800 版本，响应使用一年 immutable 缓存。浏览器不获得 OSS 凭证、不直传 OSS，也不允许后台填写任意第三方图片 URL。旧 `avatarUrl` 仅保留读取兼容，重新上传时迁移到托管对象。

## 安全与运维边界

- Bucket 只允许匿名读取处理后的公开头像，绝不允许匿名写入。
- RAM 身份只获得 `rangers/*` 所需的 PutObject、HeadObject 与受控清理权限。
- 原始上传、授权书、私人联系方式、采集包和长期归档不得进入该 Bucket。
- 生产配置门禁要求 OSS 模式、独立 HTTPS 媒体 origin、地域、Bucket、RAM 凭证和内网开关全部明确配置。
- 对象上传与目录保存不组成分布式事务，采用“先上传不可变对象、保存引用、发布前复核、延迟清理无引用对象”；上传、发布、引用感知清理，以及枚举并删除撤回头像的当前对象、历史 versionId 与删除标记均已实现。真实 OSS 的定时清理和版本化永久删除仍须验收，不能只凭普通 DeleteObject 就宣称字节已永久删除。
- 开启版本保护或等价误删保护、访问与费用告警，并定期验证媒体域名和对象可恢复性。
