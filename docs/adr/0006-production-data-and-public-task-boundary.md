# 生产数据与公开任务边界

真实注册、自动发布和赛季结算启用前，境内写模型必须迁移到 PostgreSQL；文件适配器只用于预览和单写者开发环境。Redis 与对象存储保持可选，等吞吐、缓存或归档证据表明确有需要时再引入，避免在首个生产版本制造无收益的运维面。

通用境外内容和平台榜通过统一采集器读取。Frontier 按 ADR-0007 采用境内 GitHub 快速路径与异步公开任务回退：境内可以直接读取已知公开仓库，但页面只读取境内状态；暂时不可达时保持待验证或上一成功快照，再由公开任务重试。私人邮箱和运营资料始终留在境内，公开任务只携带仓库地址、任务类型、公开标识与防重放信息。
