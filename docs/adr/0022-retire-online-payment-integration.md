# ADR-0022：退役旧在线支付接入

- 状态：已接受
- 日期：2026-08-12
- 取代：ADR-0014、ADR-0019 与 ADR-0020 中关于旧在线支付渠道运行能力的部分

## 决策

Vault2077 不再提供旧在线支付渠道的新建、通知验真、主动查询、恢复付款、关单或原路退款能力。生产运行只保留线下对公转账入口、后台银行到账核验、付款凭证、通知和人工退款申请。

已完成且已全额退款的历史测试交易不得作为可操作支付对象继续存在。数据库迁移将其付款提供方改为 `retired_online`，删除应用、商户和渠道绑定字段，仅保留金额、历史交易参考号、状态、时间、退款事实与不可变凭证，供财务和审计只读核对。

发布时必须删除 SDK、公开回调和恢复付款路由、管理端查询／关单／退款动作、所有旧渠道环境变量与生产密钥。旧研究和已采纳 ADR 作为不可变决策史保留，但不再构成当前运行授权。

## 后果

- 新订单只有 `bank_transfer`，历史中性记录只有 `retired_online`。
- 历史记录不能调用任何外部支付提供方。
- 客户退款申请仍进入客服人工处理流程，不自动改变资金或退款状态。
- 恢复旧在线支付必须提出新的 ADR、重新完成主体与产品审核，并以全新实现接入；不得恢复本次删除的密钥或代码。
