# 公开用户无账号，OPC 在线下成交（已被 ADR 0014 取代）

Vault2077 首发不建立普通用户账号体系。信息流、SiC 和边境计划公开阅读，边境计划通过仓库挑战文件验证控制权；OPC 只展示标准服务，用户通过统一联系方式转入线下确认、付款和交付。该决策牺牲站内收藏、订单和进度能力，以保持一人公司可运营的系统深度，并避免在商业模式尚未验证前引入账户、支付和敏感材料处理。

2026-07-28 起，OPC 的成交边界由 [ADR 0014](0014-opc-accountless-orders-and-alipay.md) 取代；“公开用户无账号”的决定继续有效。
