# 内容频道采用独立编辑配置

information、roadside 与 Vault 事件编排共同使用稳定的 `vault_editorial` 编辑配置，以保持标题、摘要和事件语义一致；SiC 使用独立的 `sic_editorial` 编辑配置，面向技术长文、研究材料及其术语精度。两套配置共享事实、来源、统一语言、原始字段和追溯合同，但拥有独立队列、并发、预算和故障域；SiC 中文成品必须记录语言与编辑版本，不能用英文原文复制填充中文字段。平台原生榜及 Frontier 的确定性核验、观察和排名不得使用编辑模型；Hugging Face 周论文的票数排名也在编辑前由确定性代码完成。

每套频道编辑配置映射一个主处理提供方和一个受控备用，并记录提供方、模型及提示版本。同一任务不得随机分发到多个提供方，也不得由多个提供方并行生成后择优；只有主提供方满足明确的失败条件时才切换备用，重试继续遵守幂等与发布校验。该决策接受两套配置和容量治理的额外成本，以换取频道风格稳定、处理压力隔离和故障范围收敛。
