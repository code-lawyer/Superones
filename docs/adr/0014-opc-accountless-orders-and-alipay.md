# OPC 使用无账号订单登记与支付宝服务器到账核验

OPC 标准服务允许公开用户在服务详情中直接登记订单。用户不创建 Vault2077 账号，不进入购物车，也不提交业务材料；订单只收集联系人姓名及手机号、邮箱或微信号中的至少一种，并保存下单时的服务编号、修订和公开价格快照。

订单创建成功后，服务器使用支付宝官方 Node SDK 为唯一订单号、服务标题、固定金额和明确的收款商户 PID 生成 `alipay.trade.page.pay` 或 `alipay.trade.wap.pay` 收银台链接。用户在支付宝官方页面完成付款；支付宝异步通知通过 RSA2 验签，且 APPID、通知商户 PID、订单号、金额和交易状态全部一致后，系统自动更新订单状态。通知缺失时，受保护后台使用同一 APPID 和应用私钥签名调用 `alipay.trade.query`，并在写回前核对订单保存的商户 PID、订单号和金额。

联系方式使用现有数据密钥环加密，只在受保护后台用于付款核验和服务联系。订单完成、取消或退款满 24 个月后清除加密联系方式；订单号、服务与价格快照、支付宝交易号和必要核验时间可以作为最小业务记录继续保留。生产配置缺少已上线应用、网站支付产品、商户 PID、应用私钥或支付宝公钥时，前台下单入口必须保持不可用，部署门禁必须失败。浏览器返回页面、付款截图或用户声明不得改变到账状态。

游骑兵协会不接入该订单或付款流程。用户仍直接联系外部独立顾问，Vault2077 不参与后续定价、付款、交付或争议。
