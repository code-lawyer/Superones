# OPC 使用无账号订单登记与支付宝人工到账核验

OPC 标准服务允许公开用户在服务详情中直接登记订单。用户不创建 Vault2077 账号，不进入购物车，也不提交业务材料；订单只收集联系人姓名及手机号、邮箱或微信号中的至少一种，并保存下单时的服务编号、修订和公开价格快照。

订单创建成功后，页面显示由生产配置指定的支付宝静态收款二维码、真实收款方名称、应付金额和唯一订单号。用户付款时必须备注订单号，OPC 服务团队根据支付宝真实到账记录人工更新订单状态。静态二维码不能产生可信的自动回调，页面不得仅凭展示二维码、用户截图或用户声明显示“支付成功”。

联系方式使用现有数据密钥环加密，只在受保护后台用于付款核验和服务联系。订单完成、取消或退款满 24 个月后清除加密联系方式；订单号、服务与价格快照可以作为最小业务记录继续保留。生产配置缺少真实收款码或收款方名称时，前台下单入口必须保持不可用，部署门禁必须失败。

游骑兵协会不接入该订单或付款流程。用户仍直接联系外部独立顾问，Vault2077 不参与后续定价、付款、交付或争议。
