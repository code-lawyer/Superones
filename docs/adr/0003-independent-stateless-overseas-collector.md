# 境外采集器独立于境内网站并保持无状态

境外采集器作为独立部署单元由 GitHub Actions 启动，只抓取获准公开来源、生成稳定批次并发送到境内，不运行 LLM、不保存数据库状态，也不读取 Vault 用户数据或境内处理配置。当前为保证协议与来源注册表原子升级，它与网站代码保存在同一仓库，但 workflow 只运行采集/交付入口；未来物理拆仓不是生产前置。境内 VPS 负责批次持久化、异步 LLM 处理、事件编排和公开发布。

ADR-0004 保留本决策的独立、无状态和境内处理原则，并统一为 `AcquisitionBatch` 协议；ADR-0005 进一步确定四个独立采集通道及各自节奏；ADR-0013 规定 Node 统一交付模块独占签名和重试，GitHub Actions 不触发境内处理。
