# ADR-0012：生产后台采用身份网关与可撤销应用会话

## 决策

生产后台使用独立管理来源（例如 `https://admin.vault2077.com`），允许管理员从外部浏览器进入，但不得把应用源站或裸 `/admin` 登录口直接暴露给匿名公网。

生产访问由两层共同成立：

1. 身份访问网关先按明确账号白名单执行抗钓鱼 MFA 或 Passkey 策略，并向源站注入由受信任发行者签名的短期 JWT 身份断言；
2. Vault2077 校验断言的签名、发行者、受众、时效和白名单身份，再创建保存在 PostgreSQL 中的随机不透明应用会话。

本地开发使用密码适配器，不要求外部身份网关；开发密码不得在生产接受。生产不建立可从公网直接使用的共享密码登录。

## 会话与高风险操作

- 生产 Cookie 使用 `__Host-` 前缀、`HttpOnly`、`Secure`、`SameSite=Strict` 和根路径，不设置 `Domain`。
- 应用会话空闲 30 分钟失效，绝对有效期 4 小时；服务端记录会话摘要并支持单会话撤销。
- 登录、退出、撤销、拒绝、失败和全部写操作记录稳定的管理员身份哈希，不记录完整邮箱或原始身份断言。
- 保存 OPC 草稿属于普通后台写操作；发布 OPC 目录、确认/拒绝/撤回奖品等高风险操作要求最近 5 分钟内重新通过身份网关验证。
- 浏览器确认框只表达操作意图，不构成身份再认证。

## 请求与网络边界

- 管理页面与后台接口只接受配置的管理来源；公共站来源访问管理路径返回拒绝或不存在。
- 所有浏览器写请求必须使用 JSON、自定义同源请求头，并通过 `Origin`/`Referer` 与 Fetch Metadata 校验。
- 反向代理必须覆盖而不是追加客户端转发头；源站端口只接受受信任网关或回环网络，直接访问服务器 IP 不得到达后台。
- PostgreSQL 不对公网开放。管理员通过后台界面编辑，生产进程写入数据库；不通过 SSH 手改文件或 JSON。

## 权限

生产首发只配置一个 `owner` 身份，拥有后台全部既定操作，但仍受产品权限边界、二次确认、再认证和审计约束。不为了假想人员提前建设组织、邀请、通用 RBAC 或审批流。增加第二种人员权限前必须先更新本 ADR 与后台规格。

## 验证

应用层身份断言、会话、撤销、超时、请求来源、再认证、审计和 PostgreSQL 适配在本地自动化验证。真实 DNS、TLS、身份网关策略、代理头覆盖、源站绕过、防火墙和公网限流必须在无真实数据的生产等价预发布环境验收。

## 后果

- 管理员可以通过受保护的外部网页维护 OPC 和其他人工业务，不需要登录服务器或修改生产文件。
- 身份网关承担 Passkey/MFA 与账号恢复，应用不自行实现一套高风险认证器。
- PostgreSQL 会新增可撤销后台会话表；文件会话适配器只服务本地开发。
- 部署必须提供独立管理来源、身份断言配置和预发布网络边界证据，否则后台保持关闭。
