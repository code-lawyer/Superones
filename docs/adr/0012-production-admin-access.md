# ADR-0012：生产后台采用原生 Passkey 与可撤销应用会话

## 决策

生产后台使用独立管理来源 `https://admin.superones.top`，通过项目内 WebAuthn/Passkey 验证固定唯一管理员 `lanzhouda@163.com`。公开域名不提供管理路由，Node 源站端口不对公网开放。

浏览器在管理来源上完成 resident credential 与用户验证。应用以管理域名为 RP ID，校验一次性挑战、来源、RP ID、签名和认证器计数器；校验通过后创建保存在 PostgreSQL 中的随机不透明应用会话。Passkey 私钥不进入服务器。

本地开发使用密码适配器；开发密码在生产永远不接受。生产不配置 OIDC，不建立共享密码登录，也不引入外部身份供应商。

## 引导、恢复与撤销

- 首次注册只能通过服务器 SSH 执行 `npm run admin:passkey:enroll` 生成十分钟一次性令牌；服务器只保存摘要。
- 首次注册生成十枚一次性恢复码，只在浏览器显示一次，服务器只保存摘要。
- 每枚恢复码只能兑换一个十分钟注册令牌；公网没有“找回密码”或邮件恢复。
- `npm run admin:passkey:enroll -- --revoke-existing` 撤销全部 Passkey 与应用会话，作为受 SSH 边界保护的最终恢复流程。
- 已登录 owner 可在最近五分钟 Passkey 再认证后添加或撤销凭证；不能撤销最后一个有效凭证。

## 会话与高风险操作

- 生产应用会话 Cookie 使用 `__Host-`、`HttpOnly`、`Secure`、`SameSite=Strict` 和根路径，不设置 `Domain`。
- 会话空闲 30 分钟失效，绝对有效期 4 小时；服务端支持单会话和全部会话撤销。
- 发布 OPC 目录、确认/拒绝/撤回奖品等高风险操作要求最近五分钟内再次通过 Passkey。
- ceremony 五分钟过期且只能消费一次；凭证计数器以并发安全更新防止重放。
- 登录、退出、恢复、注册、撤销、拒绝和全部写操作记录稳定身份哈希，不记录完整邮箱、明文令牌或明文恢复码。

## 请求与网络边界

- 管理页面与后台接口只接受配置的管理来源；公共站来源访问管理路径返回拒绝或不存在。
- 浏览器写请求默认使用 JSON；ADR-0016 定义的受保护头像上传允许使用带边界和长度上限的 `multipart/form-data`。两类请求都使用自定义同源请求头，并通过 `Origin`/`Referer` 与 Fetch Metadata 校验。
- 反向代理覆盖客户端转发头，Node 只监听回环网络，PostgreSQL 不对公网开放。
- 管理员通过后台界面维护业务；SSH 只用于部署、初始引导和紧急全量恢复，不直接修改业务 JSON。

## 验证与后果

自动化覆盖凭证持久化、一次性 ceremony、计数器冲突、恢复码单次消费、最后凭证保护、可撤销会话、超时、请求来源和生产配置门禁。真实浏览器认证器、DNS、TLS、源站绕过、防火墙和公网限流仍须在无真实数据的生产等价环境验收。

该决策取消付费 IDaaS 依赖，同时把凭证恢复责任明确放在离线恢复码与受控 SSH 边界。生产部署只需要独立 HTTPS 管理来源、PostgreSQL 和现有应用秘密。
