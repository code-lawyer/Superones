# ADR-0012：生产后台采用托管 OIDC 身份与可撤销应用会话

## 决策

生产后台使用独立管理来源 `https://admin.superones.top`，通过阿里云 IDaaS EIAM OIDC 授权码流程验证唯一管理员。公开域名不提供管理路由，Node 源站端口不对公网开放。

生产访问由两层共同成立：

1. Vault2077 将浏览器重定向至阿里云 IDaaS EIAM，由 IDaaS 按明确账号授权范围执行抗钓鱼 MFA 或 Passkey 策略；
2. Vault2077 通过 OIDC 授权码回调在服务端换取 Token，校验 ID Token 的签名、发行者、受众、时效、nonce 和白名单身份，再创建保存在 PostgreSQL 中的随机不透明应用会话。

本地开发使用密码适配器，不要求外部 IDaaS；开发密码不得在生产接受。生产不建立可从公网直接使用的共享密码登录。

生产应用执行 state、nonce、PKCE、授权码服务端交换、ID Token RS256/JWKS、issuer、audience 和邮箱白名单校验。唯一 owner 为 `lanzhouda@163.com`，IDaaS 应用授权范围也只包含该账户。

## 会话与高风险操作

- 生产应用会话 Cookie 使用 `__Host-` 前缀、`HttpOnly`、`Secure`、`SameSite=Strict` 和根路径，不设置 `Domain`。
- OIDC 授权事务 Cookie 是唯一例外：它只保存签名后的 state、nonce、PKCE verifier、意图和创建时间，不保存身份或应用会话，最长 10 分钟，使用 `SameSite=Lax` 以允许身份提供方顶层跳转回调，并在回调完成或失败后立即清除。
- 应用会话空闲 30 分钟失效，绝对有效期 4 小时；服务端记录会话摘要并支持单会话撤销。
- 登录、退出、撤销、拒绝、失败和全部写操作记录稳定的管理员身份哈希，不记录完整邮箱、授权码或原始 Token。
- 保存 OPC 草稿属于普通后台写操作；发布 OPC 目录、确认/拒绝/撤回奖品等高风险操作要求最近 5 分钟内重新通过 IDaaS `prompt=login` 验证。
- 浏览器确认框只表达操作意图，不构成身份再认证。

## 请求与网络边界

- 管理页面与后台接口只接受配置的管理来源；公共站来源访问管理路径返回拒绝或不存在。
- 所有浏览器写请求必须使用 JSON、自定义同源请求头，并通过 `Origin`/`Referer` 与 Fetch Metadata 校验。
- 应用会话退出必须先通过同源 JSON `POST` 完成撤销、审计和 Cookie 清除；随后对 OIDC 退出地址的 `GET` 只执行身份提供方重定向，不得修改应用状态。
- 反向代理必须覆盖而不是追加客户端转发头，并清空任何客户端伪造的旧身份断言头；Node 源站端口只监听回环网络，直接访问服务器 IP 不得到达后台。
- PostgreSQL 不对公网开放。管理员通过后台界面编辑，生产进程写入数据库；不通过 SSH 手改文件或 JSON。

## 权限

生产首发只配置一个 `owner` 身份，拥有后台全部既定操作，但仍受产品权限边界、二次确认、再认证和审计约束。不为了假想人员提前建设组织、邀请、通用 RBAC 或审批流。增加第二种人员权限前必须先更新本 ADR 与后台规格。

## 验证

应用层 OIDC 事务、Token 验证、会话、撤销、超时、请求来源、再认证、审计和 PostgreSQL 适配在本地自动化验证。真实 DNS、TLS、IDaaS 策略、回调、源站绕过、防火墙和公网限流必须在无真实数据的生产等价预发布环境验收。

## 后果

- 管理员可以通过受保护的外部网页维护 OPC 和其他人工业务，不需要登录服务器或修改生产文件。
- IDaaS 承担 Passkey/MFA 与账号恢复，应用不自行实现一套高风险认证器。
- PostgreSQL 会新增可撤销后台会话表；文件会话适配器只服务本地开发。
- 部署必须提供独立管理来源、OIDC issuer/client 配置和预发布网络边界证据，否则后台保持关闭。
