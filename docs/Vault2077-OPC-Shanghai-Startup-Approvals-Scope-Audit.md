# OPC 上海起步审批与备案报告——适用范围及收费口径审计

审计对象：[《OPC 起步阶段审批、备案与市场报价——上海及长三角研究》](Vault2077-OPC-Shanghai-Startup-Approvals-Research.md)。

审计范围仅包括：事项的作用、法定触发条件、不适用对象，以及“政府收费”和“代理/第三方报价”的表达是否会误导。法律适用性只采用政府部门、现行法规和主管机关办事指南等一手来源。本审计**没有重新统计代理市场价**，因此不能单独用来证明原报告中的市场均价准确。

## 一、审计结论

当前版本已经增加了“作用 / 谁需要 / 谁通常不需要 / 官方收费 / 代理报价”的一页式主表，方向正确；公司设立登记也已明确写成“政府 0 元、代理 500–2000 元”，回应了“政府不收费，收费的是代理机构”这一核心问题。

但在正式交付前仍建议修正以下高风险表述：

1. **“官方未列收费项目”不能写成“按 0 元理解”。** 只有主管机关办事指南明确写明“不收费/免费”，才可以列“官方收费 0 元”。算法备案、生成式 AI 备案/登记、受益所有人备案等没有查到明确收费标准的，应写“官方公开规则未列收费项目；不等同于取得官方 0 元报价”。
2. **算法备案不等于大模型备案。** 算法推荐规则还覆盖个性化推送、排序精选、检索过滤、调度决策等技术；即使完全不使用大模型，仍可能因为其他算法服务而进入判断范围。反过来，既不用 AI，也不提供上述算法推荐服务的创业者，不需要算法备案。
3. **自研或微调不是生成式 AI 备案的独立触发条件。** 核心门槛是是否向境内公众提供生成式 AI 服务，以及该服务是否具有舆论属性或社会动员能力。纯内部研发、内部办公或未向境内公众提供服务，不适用《生成式人工智能服务管理暂行办法》。
4. **调用已备案模型 API 不需要重新做基础模型备案，但可能需要应用登记。** 面向公众上线、直接调用已备案大模型能力的应用或功能，应按属地网信部门要求办理应用登记并公示模型名称及备案号。原报告不应把“没有自研模型”理解成“AI 合规事项全部为零”。
5. **等保备案和等保测评必须拆行。** 二级以上系统需要向公安机关备案；现行《信息安全等级保护管理办法》第十六条只明确第三级以上备案时同时提交测评报告。不能把“等保二级备案”与 4万–5万元测评套餐捆绑成所有二级系统统一的法定开业成本。
6. **ICP 备案、ICP 许可、EDI 许可是三种不同事项。** 上海市通信管理局明确：增值电信业务经营许可和 ICP 备案均不收费，且从未指定任何第三方代理。代理收费只能叫材料、申报、整改或咨询服务费。
7. **“上海及附近平均报价”仍需避免过度统计化。** 只有一个样本或样本服务边界不一致的项目，应叫“公开报价样本/预算锚点”，不能叫“地区平均价”。商标代理总价若含 270 元官费，也不能直接与不含官费的报价取平均。

## 二、建议统一的价格结构

每一事项建议固定为以下六列，任何费用都只进入一个栏位：

| 栏位 | 应写内容 | 不应混入 |
| --- | --- | --- |
| 官方收费标准 | 主管机关明确的“不收费/免费”或法定收费金额 | 代理服务、银行套餐、测评、云资源 |
| 代理服务费 | 材料整理、填报、沟通、进度跟踪等人工服务 | 政府规费、第三方硬成本 |
| 第三方必要成本 | 银行产品、域名、服务器、测评、检测、审计、场地等 | 代理人工服务 |
| 是否可自办 | 可自办 / 必须经接入商提交 / 需专业机构测评等 | 不用“代办”暗示法定强制 |
| 报价口径 | 含税、是否含官费、样本数、地域、服务边界 | 模糊套餐价 |
| 结论标签 | 样本均价 / 区间中点 / 单一样本 / 预算锚点 | 用单一样本冒充平均价 |

政府部门通常发布的是“收费标准”，不是市场意义上的“官方报价”。因此建议全文把“官方报价”统一改为“官方收费标准”。

## 三、数字业务事项逐项审计

### 3.1 网站 ICP 备案

- **作用**：为在境内提供的非经营性互联网信息服务建立主办者、网站/应用和网络资源信息档案，并取得备案编号。
- **触发条件**：在中华人民共和国境内提供非经营性互联网信息服务。网站、APP 等不同载体的具体填报路径不同。
- **明确不适用**：没有对外网站或 APP 等互联网信息服务的纯线下经营者；经营性互联网信息服务不能用普通 ICP 备案替代经营许可。
- **需要修正的边界**：原报告用“境内服务器”作为核心判断过窄。《非经营性互联网信息服务备案管理办法》以“在境内提供非经营性互联网信息服务”为法定口径。实践中是否使用境内接入资源会影响备案路径，但不宜仅凭“服务器在境外”就作无须备案的绝对结论。
- **官方收费**：上海市通信管理局明确 ICP 备案不收费，也未指定第三方代理。代理平台收取的数百元是可选增值服务费，不是备案费。
- **官方来源**：[工信部《非经营性互联网信息服务备案管理办法》第二、五、八条](https://www.miit.gov.cn/gyhxxhb/jgsj/cyzcyfgs/bmgz/xxtxl/art/2024/art_84a0cfa0ebd049bbbe751dca9a008e56.html)；[上海市通信管理局关于审批、代理及收费的公告](https://shca.miit.gov.cn/zwgk/zcwj/wjfb/art/2024/art_d4f09cb8e7004ac19c2af7f6fd8fb32a.html)。

**审计评级：需小幅修订。** 官方与代理价格已分开，但“不使用境内接入资源通常不走备案路径”应改成风险提示，不能作为法律豁免结论。

### 3.2 公安机关国际联网备案（公网安备）

- **作用**：向公安机关登记国际联网主体、联网业务和安全责任信息；它与工信部 ICP 备案、等级保护备案不是同一事项。
- **触发条件**：《计算机信息网络国际联网安全保护管理办法》第十二条规定，互联单位、接入单位以及使用国际联网的法人和其他组织，应自网络正式联通之日起 30 日内办理备案。上海公安实务通过互联网安全综合服务网办理网站、APP 等入网登记。
- **明确不适用**：没有网站、APP 或其他对外联网业务的主体，不应购买“网站公网安备代办”。但法规文字的主体范围比“公开网站”更宽，复杂联网业务应向属地网安部门确认，不能把“没有公开网站”写成所有国际联网备案义务的绝对豁免。
- **官方收费**：上海“一网通办”明确“是否收费：否”“中介服务：无”，因此政府收费可写 0 元；市场上的代填、材料整理费是自愿代理服务费。
- **官方来源**：[《计算机信息网络国际联网安全保护管理办法》第十二、二十三条](https://www.miit.gov.cn/jgsj/xxjsfzs/xxgk/art/2020/art_25af2145083b40e98cc4993438703d78.html)；[上海“一网通办”国际联网备案](https://zwdt.sh.gov.cn/govPortals/bsfw/item/4afb05c3-dd35-4b22-a974-a920406c690d)；[上海市公安局网站备案答复](https://gaj.sh.gov.cn/shga/wzShgarxPjxx/getPjPage?pa=9974a4abdb9d012603433608f85f7547)。

**审计评级：需要统一收费证据。** 主表写“0 元”是正确的，详表仍写“官方页面未列收费”，应统一改为“上海官方 0 元、无中介服务”。

### 3.3 APP / 小程序备案

- **作用**：取得境内移动互联网应用程序的备案编号，供应用接入、分发和公众核验。
- **触发条件**：在中华人民共和国境内从事 APP 互联网信息服务。工信部通知同时覆盖 APP 分发平台中的小程序、快应用等形态。
- **明确不适用**：没有 APP、小程序或快应用的经营者；仅做网站时办理网站对应备案，不购买 APP 备案服务。
- **官方收费**：互联网信息服务备案本身不收费；通过平台购买的“备案管家”属于自愿代理服务。
- **官方来源**：[工信部《关于开展移动互联网应用程序备案工作的通知》第二部分](https://www.miit.gov.cn/zwgk/zcwj/wjfb/tz/art/2023/art_920db564162e4312916a01bed6540ad8.html)；[上海市通信管理局收费与代理公告](https://shca.miit.gov.cn/zwgk/zcwj/wjfb/art/2024/art_d4f09cb8e7004ac19c2af7f6fd8fb32a.html)。

**审计评级：基本合格。** 建议把“APP 备案代理 1,000 元”明确标为可选增值服务，并补充“接入服务商或分发平台依法承担代提交、核验职责，不等于政府指定收费代理”。

### 3.4 ICP 许可证

- **作用**：允许公司依法经营属于许可范围的互联网信息服务。
- **触发条件**：通过互联网向用户有偿提供信息或网页制作等经营性互联网信息服务，并落入增值电信业务许可范围；申请主体应满足电信许可条件。
- **明确不适用**：纯展示型官网、无偿公开信息服务、纯线下服务；“网站能收费”或“有会员”不能单独作为需要 ICP 许可证的结论，仍须看收入对应的服务和业务分类。
- **官方收费**：上海市通信管理局明确许可免费且未指定代理。数千至上万元均为代理、材料、系统整改或条件补齐服务，不是政府收费。
- **官方来源**：[现行《互联网信息服务管理办法》第三、四、七条](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_483f0dd8eb1b4dc5961e4e008bd4a083.html)；[上海增值电信业务办事指南“许可收费：免费”](https://shca.miit.gov.cn/bsfw/bszn/dxsc/blcx/art/2020/art_7426922df3754a189aaf4278ff0c7b1d.html)；[上海市通信管理局收费与代理公告](https://shca.miit.gov.cn/zwgk/zcwj/wjfb/art/2024/art_d4f09cb8e7004ac19c2af7f6fd8fb32a.html)。

**审计评级：法律边界基本合格，价格标题需改。** “ICP 许可证 11,400 元”必须始终写成“代理服务样本均价”，不能脱离“政府收费 0 元”单独出现在摘要里。

### 3.5 EDI 许可证

- **作用**：允许公司经营在线数据处理与交易/事务处理电信业务。
- **触发条件**：利用连接公用通信网或互联网的数据与交易/事务处理平台，为用户提供在线数据处理、交易处理、电子数据交换或网络/电子设备数据处理业务。
- **明确不适用**：单纯展示商品、销售自有商品或自有服务的网站，通常不因具有下单功能就自动构成 EDI；平台角色、交易链路、服务对象和收费对象需要逐案判断。
- **官方收费**：属于增值电信业务经营许可，上海官方免费；代理费不是许可费。
- **官方来源**：[工信系统《电信业务分类目录》B21](https://qhca.miit.gov.cn/zwgk/zcwj/flfg/art/2022/art_0a66ad8c82c94c77bf56d698a1f35d64.html)；[上海增值电信业务办事指南](https://shca.miit.gov.cn/bsfw/bszn/dxsc/blcx/art/2020/art_7426922df3754a189aaf4278ff0c7b1d.html)；[上海增值电信业务经营许可常见问题清单](https://shca.miit.gov.cn/bsfw/bszn/dxsc/blcx/art/2022/art_5c0702e60552429cae3813314b156951.html)。

**审计评级：适用边界合格，价格统计名称不合格。** 原报告只有一个明确上海样本时，应写“8,800 元单一样本/9,000 元预算锚点”，不写“上海平均价”。

### 3.6 等保定级、备案、测评和整改

- **作用**：定级用于判断系统遭破坏后的影响程度；第二级以上备案用于接受公安机关等级保护监督；测评用于评价安全保护状况；整改用于补齐技术和管理差距。
- **触发条件**：网络运营者应履行等级保护义务；新建系统应在规划设计阶段确定安全保护等级。已运行或新建的第二级以上信息系统在规定期限内向公安机关备案。
- **明确不适用**：纯线下、没有自建或运营网络系统的经营者，不需要购买等保备案套餐。一个简单官网也不能仅凭“有网站”就直接判定为二级或三级。
- **关键纠偏**：现行《信息安全等级保护管理办法》第十六条明确**第三级以上**备案时同步提交测评报告，没有把二级测评报告列为同等备案材料。上海主管机关如对具体二级系统另有材料或行业要求，应以当期办事指南和行业规则为准，但代理不得把 4万–5万元测评说成“政府备案费”。
- **官方收费**：上海等保备案办事指南明确“不收费”且“中介服务：无”，因此备案官费为 0 元。测评、渗透测试、安全设备、云资源和整改开发均为第三方或内部成本。
- **官方来源**：[2026 年现行《网络安全法》第二十三条](https://isccc.gov.cn/xxgk1/zcfg_3/flhxzfg/202603/t20260305_11199.htm)；[《信息安全等级保护管理办法》第十五、十六、四十二条](https://www.miit.gov.cn/jgsj/xxjsfzs/xxgk/art/2020/art_a981907528694176a61b5b52c2d19895.html)；[上海“一网通办”网络安全等级保护备案](https://zwdt.sh.gov.cn/govPortals/bsfw/item/9f0acbb4-4e5e-4517-ae6c-54285f93c5b9)。

**审计评级：必须修订。** 建议拆为“等保定级（内部工作）”“二级以上公安备案（官方办理）”“等级测评（第三方服务）”“安全整改（第三方/内部成本）”四行，并删除“等保二级备案及测评 45,000 元”这种合并标题。

### 3.7 算法推荐备案

- **作用**：向网信部门填报具有舆论属性或社会动员能力的算法推荐服务的主体、服务形式、应用领域、算法类型、自评估报告和拟公示内容。
- **触发条件**：第一层先判断是否在境内应用算法推荐技术提供互联网信息服务；算法推荐技术包括生成合成、个性化推送、排序精选、检索过滤、调度决策。第二层再判断服务是否具有舆论属性或社会动员能力；达到该条件才触发第二十四条备案。
- **明确不适用**：既不使用生成合成、个性化推送、排序精选、检索过滤、调度决策等算法向用户提供互联网信息服务，也不向公众提供相关服务的创业者；纯内部工具和内部自动化通常不进入该备案范围。
- **必须保留的反例**：不使用“大模型”不代表一定不需要算法备案。电商个性化推荐、信息流排序、网约配送调度等并不以大模型为前提，也可能属于算法推荐服务。
- **官方收费**：规则没有列明行政收费标准。没有主管机关明确的“不收费”办事指南时，应写“官方规则未列收费项目”，不能写“按 0 元理解”。8,000–20,000 元是代理/咨询/材料服务报价。
- **官方来源**：[《互联网信息服务算法推荐管理规定》第二、二十三至二十七条](https://www.cac.gov.cn/2022-01/04/c_1642894606364259.htm)。

**审计评级：必须修订收费措辞，适用边界需增强。** “不使用 AI/算法服务者不需要”基本正确，但应拆开大模型与其他算法，避免让读者误以为算法备案只和 AI 大模型有关。

### 3.8 生成式 AI 服务备案、安全评估和应用登记

- **作用**：安全评估和算法备案针对具有舆论属性或社会动员能力的公众生成式 AI 服务；应用登记用于直接调用已备案模型能力上线的公众应用或功能，由属地网信部门管理，并公示使用的模型名称和备案号。
- **触发条件**：先判断是否利用生成式 AI 技术向境内公众提供生成文本、图片、音频、视频等内容的服务；再根据是否具有舆论属性或社会动员能力、是否直接调用已备案模型等，分别走备案/安全评估或应用登记路径。
- **明确不适用**：完全不提供 AI 功能者；企业、教育科研机构等仅研发或内部应用、未向境内公众提供生成式 AI 服务者；员工使用第三方办公 AI 工具的普通企业。
- **调用 API 的边界**：单纯调用已备案基础模型，不需要把基础模型再备案一次；但是把该能力集成进面向公众的产品后，应用方仍应核验属地登记和公示要求。
- **原表需要纠正之处**：成文规则只对“安全评估 + 算法备案”明确写了“具有舆论属性或社会动员能力”的门槛；国家网信办后续公开的“直接调用已备案模型的应用登记”表述没有再次附加该限定。因此，原主表把应用登记也限定为必须具有舆论属性或社会动员能力，口径偏窄；面向公众上线的 API 应用应先向属地网信部门核验登记，而不是自行判定豁免。
- **自研/微调的边界**：自研、开源部署、微调只是技术来源，不是独立法定触发器。内部微调模型不因“微调”两个字自动产生备案义务；面向公众提供且符合监管条件时才进入备案/评估判断。
- **官方收费**：现行规则和国家网信办公告未列行政收费标准，不应写“按 0 元理解”。95,000 元只能称“单一代理项目样本”，不能称官方价或地区均价。
- **官方来源**：[《生成式人工智能服务管理暂行办法》第二、十七、二十二条](https://www.cac.gov.cn/2023-07/13/c_1690898327029107.htm)；[国家网信办生成式人工智能服务已备案信息公告](https://www.cac.gov.cn/2024-04/02/c_1713729983803145.htm)；[国家网信办《国家信息化发展报告（2024 年）》关于直接调用已备案模型的应用登记](https://www.cac.gov.cn/rootimages/uploadimg/1750919392492395/1750919392492395.pdf)。

**审计评级：必须拆成两至三行。** 推荐分别列“公众生成式 AI 服务合规判断”“具有舆论属性或社会动员能力服务的安全评估及算法备案”“调用已备案模型的应用登记与公示”。原“自研/微调大模型备案 95,000 元”不宜作为所有自研模型的默认起步事项。

## 五、建议直接替换的 AI 判断话术

> **不用 AI 的创业者是否需要算法备案？**
>
> 如果既不向用户提供生成合成、个性化推送、排序精选、检索过滤、调度决策等算法推荐服务，也不向境内公众提供生成式 AI 功能，通常不需要算法备案、生成式 AI 应用登记或大模型备案。仅在企业内部使用现成 AI 办公工具，也不适用面向境内公众的生成式 AI 服务备案规则。
>
> 但“不使用大模型”不等于一定没有算法备案问题：个性化推荐、信息流排序、搜索过滤和平台调度也可能属于算法推荐服务。反过来，直接调用已经备案的大模型 API 面向公众上线，不需要重新备案该基础模型，但应核验属地应用登记和模型信息公示要求。

## 六、主报告修订优先级

### P0：交付前必须改

1. 将所有“官方未列收费，按 0 元理解”改为“官方规则未列收费项目”；只有官方指南明确“不收费”的保留 0 元。
2. 把等保备案与二级测评、整改拆成不同事项，删除把 45,000 元写成二级备案整体成本的表述。
3. 把“算法备案”“生成式 AI 服务安全评估/算法备案”“调用已备案模型的应用登记”拆开。
4. 把“自研/微调大模型备案”改成条件式名称，明确内部研发、自用、未向公众提供服务者不适用。
5. 修正一页式主表与后文详表在公网安备收费上的矛盾口径。

### P1：强烈建议改

1. 摘要中的每个市场数字都加“代理/第三方”前缀，避免数字脱离官方 0 元语境。
2. EDI 和大模型项目只有单一样本时，不使用“平均价”。
3. 银行商业收费、代理陪同费、测评费、云资源费各自单列，不进入“代理均价”同一列。
4. 商标代理报价统一成“代理服务费（不含官费）”或“含官费总价”一种口径后再计算均值。

## 七、最终审计意见

原报告的结构已经比初稿清楚，但仍不能把“一页式价格表”直接当成所有 OPC 的统一采购单。最稳妥的交付逻辑应当是：

1. 先问主体类型和真实经营活动；
2. 再筛出法定必办、业务触发、自愿和非审批事项；
3. 每项先展示官方收费标准，再展示可选代理费和第三方硬成本；
4. 对网站、App、平台、等保和 AI 使用独立事实问卷，不做默认勾选；
5. 没有直接官方收费证据时，不把“未列收费”推定成“官方报价 0 元”。

这套口径能明确回答用户最关心的问题：**公司注册等政府办理可以是 0 元；市场上收取的是代理服务费。没有网站、App、平台、受监管行业或公众 AI 功能的人，不需要购买对应备案/许可代理套餐。**
