# Vault2077 后台与运营首版设计基线

> 状态：规范性文件。后台服务于极简运营，不改变公开产品的自动化原则。

## 1. 后台任务

后台只处理真实业务输入、用户报告的错误、外部依赖故障和必须人工完成的资格或专业确认。正常资讯采集、翻译、摘要、事件匹配、SiC 排名和边境榜单计算均自动完成，不进入日常人工审批队列。

本地开发可以使用开发专用密码适配器。生产后台使用独立管理来源和身份访问网关：只有白名单中的 `owner` 身份通过 Passkey 或其他抗钓鱼 MFA 后，应用才接受网关签名身份断言并创建可撤销会话。生产不提供可由匿名公网直接尝试的共享密码登录，也不建设组织、邀请、通用 RBAC、审批流、全站富文本搭建器或复杂数据大屏。OPC 菜单是面向结构化服务目录的窄编辑器，不构成可改写资讯、来源、榜单或任意页面的通用 CMS。

采集、处理和来源健康诊断属于后台/本地运营能力。`/pipeline` 不进入公开导航，也不得向未认证公开用户展示服务器、跨区域拓扑、模型、阈值、源站错误或内部配置。

## 2. 权限边界

生产首发只配置一个 `owner` 身份；所有写操作必须二次确认、记录操作日志并可识别管理员身份哈希和目标记录。保存草稿不要求重复登录，发布目录和确认、拒绝或撤回奖品等高风险操作必须在最近 5 分钟内完成身份网关再认证。后台不能：

- 手工修改事件证据、Star 快照、Star 基线或榜单分数；
- 绕过 OPC 专业复核发布服务；
- 将私密报名字段复制到公开内容；
- 把未通过结构化校验的模型输出直接发布；
- 用后台新增任意抓取 URL 绕过来源治理。

## 3. 登录与会话

- 管理页面和后台接口只接受配置的独立管理来源；公共站来源、服务器 IP 或绕过身份网关的请求不得进入后台。
- 身份网关必须对明确账号白名单执行 Passkey 或其他抗钓鱼 MFA，并注入短期签名 JWT；应用校验签名、发行者、受众、时效和白名单身份。
- 本地开发密码至少 20 个字符并使用 Argon2id 哈希能力测试；开发密码适配器在 `NODE_ENV=production` 下关闭。
- 应用会话使用服务端随机不透明令牌，数据库只保存带密钥摘要。会话可单独撤销，空闲 30 分钟失效，绝对有效期 4 小时。
- 生产 Cookie 必须使用 `__Host-` 前缀、`HttpOnly`、`Secure`、`SameSite=Strict` 和根路径，不设置 `Domain`。
- 所有浏览器写请求必须是 JSON，携带受控同源请求头并通过 `Origin`/`Referer` 与 Fetch Metadata 检查。
- 身份断言缺失/无效、会话创建/撤销、登录拒绝和锁定事件进入安全日志，但不保存原始 JWT、完整邮箱、明文秘密或完整 IP。

## 4. 后台导航

固定为：运行概览、内容异常、来源组合、OPC 菜单、边境计划、系统记录。

运行概览只显示需要行动的信息：最近四个批次、失败任务、暂停来源、待处理纠错、待专业复核服务、待结算事项。内容处理按 `vault_editorial` 与 `sic_editorial` 分别显示积压、当前并发、预算、主/备用健康和最近切换；正常指标不做装饰性图表。

首次上线期间，运行概览还必须显示 bootstrap 与 incremental 的区别、SiC 各 approved 来源的基线完成状态、Vault 基线窗口和失败补跑入口。重复运行只能补齐缺失来源，不得重复发布或覆盖原始发布时间。

## 5. 内容异常与纠错

公开用户只能提交误合并、信息错误、来源失效三类纠错报告。后台操作：

- 查看报告及关联事件或资讯；
- 隐藏或恢复资讯；
- 把资讯从错误事件移出并加入另一个现有事件；
- 将事件拆为两个事件；
- 更新来源失效状态；
- 触发翻译、资讯摘要或事件摘要重算；
- 关闭报告并记录处理说明。

LLM 不自动处理历史误合并。人工操作必须保留原记录、前后关联和时间；公开页面只显示当前有效结果，不暴露内部备注。

## 6. 来源组合治理

人工批准对象是“来源组合修订”和其中的生产来源边界。参考项目或自有来源包中的具名条目只能自动进入候选注册表，不能因为上游项目获批就自动获得生产准入；每个生产入口必须明确归入机构新闻、路边社、SiC 内容组或平台榜之一。

同一原始内容只有一个主去向。机构宽泛 Feed 无法用固定栏目、路径或专用入口稳定区分新闻与深度材料时保持待审，不允许运营人员把逐篇主路由交给 LLM。Hacker News 与 Lobsters 作为社区原生来源整体准入，其外链不展开为新的生产来源。

后台可查看来源组合版本、发现的逻辑发布者和通道、最近成功、失败率及暂停状态。系统可以因连续失败自动暂停单个通道；恢复可以自动健康检查或人工触发。后台不得接受请求参数中的任意 URL 直接采集。

运营人员可以暂停或恢复某个频道编辑配置、触发受控备用和重试失败任务，但每次操作必须记录原因。后台不得把同一任务同时交给多个提供方、从多个生成结果中人工择优，或通过临时提示词改变频道事实标准。

首批来源组合固定为 2026-07-22 信源审计报告所列七组项目的固定提交，经去重和在线核验后生成运行 bundle；后续增删或升级仍遵循本节治理方式。

## 7. OPC 菜单

后台支持基础设施、专项服务和游骑兵公开档案的新增、删除、排序、编辑、草稿、专业复核状态、修订、发布和停售，并维护游骑兵本人授权的公开联系渠道。三个一级入口、三个基础设施浏览分组、六个专项专业领域和十个游骑兵身份仍由规格控制，运营人员不能把 OPC 编辑器扩展为任意栏目。

编辑与发布分离：保存草稿不会改变公开页面；发布使用当前草稿整体替换公开快照，必须二次确认并检查预期修订号。发生并发版本冲突时返回冲突并要求刷新，不能以后到请求静默覆盖。每次发布保留完整目录快照和不可变审计摘要。

正式发布前执行字段完整性检查；价格、范围、材料、周期、成果、修订、公开状态和游骑兵本人授权联系方式任一缺失或仍为预览占位值即阻止发布。

后台只记录专业负责人已确认的结果，不取代专业负责人作出法律、税务或其他专业判断。

## 8. 边境计划

后台支持查看报名和当前赛季状态；奖品捐献只提供查看待确认记录、确认并加入随机奖池、拒绝和结算前撤回。

所有排名值、最终资格、季度冠军和随机分配结果只读。每小时 Star 更新、季度结算、最终资格检查和随机奖品分配均由系统执行；后台不得修改 Star、基线、名次、指定奖品获得者或重复抽取。确认、拒绝或撤回奖品属于边境计划后台的写操作，必须明确目标奖品和结果。

## 9. 操作日志

每个写操作记录：时间、稳定管理员身份哈希、会话标识、动作、目标类型、目标 ID、结果、原因和不含敏感数据的差异摘要。日志不可通过普通后台界面修改或删除。

首发只有一个 `owner`，但其身份来自受信任网关而不是共享口令，因此审计可以把不同会话归到同一管理员。增加第二类人员权限时必须先修订本规格，不在环境变量中临时发明权限。

## 10. 失败与安全状态

- 数据库或存储不可用：后台只读并阻止写操作。
- 外部依赖失败：显示稳定错误码、最近成功时间和安全重试，不展示密钥或原始响应正文。
- 部分批次失败：保留上一公开版本，允许针对失败任务重试。
- 高风险操作冲突：以后到达的请求不得静默覆盖先前状态，返回冲突并要求刷新。
- 会话过期或被撤销：写操作返回未授权，前端保留未提交表单内容并要求重新进入安全身份入口。
- 高风险操作再认证过期：返回稳定错误码和再认证入口，不丢弃已保存草稿，也不执行目标操作。
- 身份网关或 JWKS 暂时不可用：不创建新会话；已建立且未过期的应用会话继续按既定权限工作，后台显示身份入口降级。

## 11. 验收标准

- 未登录、错误管理来源、无有效身份断言或被撤销会话无法获得任何后台数据。
- 生产身份网关强制白名单与抗钓鱼 MFA；本地密码尝试受到限速和锁定，会话符合 Cookie 安全要求。
- 公共站域名和服务器 IP 不能访问管理页面或后台接口；源站只接受受信任网关。
- 会话可以单独撤销；高风险写操作在再认证超时后被拒绝。
- 正常内容发布无需人工批准；历史纠错只能由人工执行。
- 来源组合获批后，其明确来源自动进入候选注册表；只有完成用途、入口边界和单一主去向审核的来源进入生产。
- 任何公开数据修改、资格处置和服务发布都有操作日志。
- 后台无法直接写入排名数值或发布不完整的 OPC 服务。
- OPC 草稿、发布快照、版本冲突和增删改顺序通过同一服务目录接口验证；公开 OPC 路由只读取已发布快照。
- 身份断言、完整管理员邮箱、会话摘要、私人邮箱、挑战哈希、LLM 密钥和原始敏感日志不出现在客户端响应。
- Vault 与 SiC 的队列、并发、预算和故障切换相互隔离，切换操作可追溯且不会改变榜单或 Frontier 确定性数据。
