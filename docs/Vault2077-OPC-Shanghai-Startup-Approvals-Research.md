# OPC 起步阶段审批、备案与市场报价——上海及长三角研究

> 调研截止：2026-07-31。
> 证据口径：工作区上下文使用仓库原始文档；外部流程优先使用上海市政府、上海市市场监管局、上海税务、上海人社、上海公积金、上海公安、人民银行、市场监管总局、工信部、网信办、国家版权局、国家知识产权局等官方一手来源。市场价格采用上海市企业服务云、阿里云/腾讯云市场及上海、苏州、杭州服务商公开标价。
> 本研究分别列示“政府规费”“代理/第三方市场价”和“持续经营成本”，不能用代办价格反推政府收费。

## 1. OPC 在本项目中的含义已经明确

工作区中的 OPC 是 Vault2077 面向“超级个体 / 一人公司”的服务台概念，英文语义接近 **One Person Company**，但不是一个法定登记类型，也不应默认等同于“只有一个股东的有限责任公司”。

- [CONTEXT.md](../CONTEXT.md) 将“一人公司”定义为一名核心经营者主导、借助外部专业人员或自动化能力运行的商业主体。
- [PRODUCT.md](../PRODUCT.md) 将 OPC 服务台的目标用户明确为技术型超级个体与一人公司，典型规模一至三人。
- [既有全国研究](Vault2077-OPC-Infrastructure-China-Needs-Research.md) 已明确：服务对象可能处于自然人偶发经营、个体工商户、个人独资企业或单一股东有限责任公司等不同状态。

因此，本次“OPC 起步阶段”应理解为：**上海及周边个人主导经营主体，从筹备到具备一般经营条件所需的登记、许可、备案和后续申报**。不能把所有用户统一套入“一人有限公司注册套餐”。

## 2. 使用口径

| 标记 | 含义 |
| --- | --- |
| **必办** | 选择该主体或开展该类活动后，原则上必须办理 |
| **触发** | 只有雇人、开网站、做平台、经营特定行业等事实出现后才办理 |
| **自愿** | 法律不以登记作为权利产生前提，但登记有确权、举证或商业价值 |
| **非审批** | 是商业开户、内部治理或技术实施，不应包装成政府审批 |

“官方规费”只指政府机关收取的行政事业性收费；云服务、银行套餐、印章增刻、测评、审计、代理、加急等第三方费用不在其中。

### 3.2 上海开办“一件事”与长三角可比口径

上海“企业登记在线”将营业执照、印章、发票、基本社保等纳入一个环节、一天、零费用的开办服务。[上海企业登记在线](https://www.shanghai.gov.cn/affairs_affairs/8181238d888941118f3b52a0dfa1c6a3.html)

周边地区的官方“一件事”范围与上海基本一致：

- 江苏企业开办“一件事”列明市场主体登记、公章刻制、银行开户登记、发票和税控设备申领、就业参保登记、住房公积金缴存登记，页面口径为 0.5 个工作日。[江苏政务服务企业开办一件事](https://scjg.jszwfw.gov.cn/allLinks/business/gxyjs/open/open.html)
- 浙江地方企业开办“一件事”指南同样覆盖企业登记、公章刻制、发票、员工参保、公积金及银行预约开户。[浙江岱山企业开办“一件事”指南](https://zjjcmspublic.oss-cn-hangzhou-zwynet-d01-a.internet.cloud.zj.gov.cn/jcms_files/jcms1/web2548/site/attach/0/3790795f456348678e920bb4649d7a83.pdf)

这意味着上海、江苏、浙江的“政府开办环节”可以作为同类服务比较，但**注册地址、园区托管、银行实地核验、代理记账、税控风险处理等市场价格不能混入政府规费**。

## 6. 不应列为“审批备案”的常见项目

以下项目可能很重要，也可能产生真实市场费用，但不能冒充政府审批：

- 公司章程、单一股东决定、印章与网银权限、注册资本出资日历；
- 代理记账、纳税申报、年度汇算、发票操作；
- 银行基本户开户本身及银行尽职调查；
- 域名购买、云服务器、企业邮箱、SSL 证书；
- 隐私政策、用户协议、合同、开源合规和数据台账；
- 等保测评、渗透测试、安全整改、审计与律师意见；
- 商标检索、软著材料整理、知识产权代理。

这些应在最终价格表中列为“市场服务/第三方费用”，与“政府规费 0 元”并排展示。

## 7. 上海及附近地区市场报价

### 7.1 计算口径

本节不是政府发布的价格指数，而是截至 2026-07-31 的公开报价样本预算基准：

1. 地域以**上海**为核心，以**苏州、杭州、嘉兴**等通勤及服务半径内城市作辅助样本；
2. 有明确单价时直接采用；有区间时取区间中点；有多个可比样本时，对中点作算术平均并取整；
3. 排除仅写“0 元/免费”但没有完整履约边界的引流价；政府本身确实免费的事项仍记为 0 元；
4. “平均价”只比较同一范围的基础服务，不含注册地址、人员社保、网站整改、系统开发、安全整改、加急、审计、律师意见等未明确包含项；
5. 公开页面通常未明确是否含税，采购时应要求供应商写明**含税总价、发票类型、第三方费用和退款条件**。


报价时必须特别防止四类误导：

1. 把上海“开办企业零费用”包装成高额“政府注册费”；
2. 把银行开户、代理记账、注册地址和印章增刻打成不可拆分套餐；
3. 把 ICP 备案、公网安备、APP 备案、ICP/EDI 许可、等保备案混成一个“互联网资质”；
4. 把商标、软著、等保测评等自愿或条件性事项说成所有 OPC 开业前必办。

## 9. 最终结论

1. OPC 没有独立审批；首先要做的是主体和真实业务分类。
2. 上海通用开办主流程已高度集成：主体登记、首套印章/电子印章、税务开业、发票、基本社保、公积金等大量事项可在线联办，官方口径为一个环节、一天、零费用。
3. 单一股东有限公司最容易遗漏的是受益所有人备案/承诺免报判断、银行账号向税务报告、工商年报和即时信息公示。
4. 数字业务不能用一张固定清单覆盖全部公司：ICP 备案、公网安备、APP 备案、ICP/EDI 许可、等保备案、算法或生成式 AI 备案均由不同业务事实触发。
5. 商标和软件著作权登记不是开业审批；商标有明确官方规费，软件著作权登记费已经停征。
6. 本研究的“上海及附近平均报价”按同口径公开样本计算，并把官方规费、第三方硬成本和代理服务费分栏；C 级项目应在采购前再取得至少三份书面报价。
7. 对普通、非许可行业的 OPC，上海政府开办环节可为 0 元；选择代办、银行基础产品和小规模代理记账后的首年常见预算约为 **4650 元**，需要付费地址时约为 **6250 元**。
8. 数字业务成本的分水岭不是“有没有网站”，而是是否进入经营性信息服务、第三方交易平台、等保二级以上或公众 AI。此时市场服务费会从几百元跃升到 1 万、5 万甚至 10 万元级。

本笔记不构成法律、税务、会计、电信、网信或知识产权个案意见。行业许可、经营性互联网服务、数据跨境、公众 AI 服务等高变异事项，在报价前必须完成事实问卷和专业复核。
