# Vault2077 生产上线清单

本清单是发布门禁，不创造新需求。任何 P0 未通过都不得启用真实报名、自动发布、收款或赛季结算。

## P0：产品与内容

- [ ] 四个频道的真实内容/业务输入已确认，页面没有把演示数据冒充实时数据。
- [ ] OPC 与游骑兵采用后台渐进发布：首发不设服务条目数量或顾问人数下限；每一项公开服务均已填写真实价格、范围、材料、成果、验收、周期和限制，并经 OPC 菜单草稿/校验/发布；每一份公开游骑兵档案均取得本人授权且联系方式真实。空目录显示诚实空状态，不发布示例服务、虚构档案或不可履约内容。
- [ ] OPC 纸质签约与付款使用独立门禁：未接入时 `VAULT2077_OPC_PAPER_CHECKOUT_ENABLED=false` 或 `VAULT2077_OPC_PAYMENTS_ENABLED=false`，不渲染收集表单且 API 返回 503；开放前在线订单及预付款协议、固定金额支付宝支付/查询/全额退款/退款查询、订单状态、加密寄送地址、付款凭证、付款邮件 outbox 和后台审计均已完成沙箱与生产演练。`VAULT2077_OPC_ESIGN_ENABLED=false` 不得阻止纸质下单。
- [ ] SiC 只展示经 GitHub 官方 REST API 获取的 OpenGithubs 日/周/月聚合榜、Hugging Face Trending 与 OpenRouter `top-weekly`，无网页抓取、Skill、MCP 或本地自算增量。
- [ ] 边境计划当前赛季奖励已在后台保存并经重新认证发布；对外组织、实际责任主体、税费扣缴、赛季结束后一周内开放奖励流程、奖品条款、隐私告知和联系流程一致。
- [ ] 法律文本、版权处理、隐私与数据保留规则通过业务/法律确认。

## P0：采集与处理

- [ ] 只有一个境外采集 workflow 文件和一个规范接收协议。
- [ ] information、roadside、sic、rankings 四通道按规定节奏独立运行并可观测。
- [ ] 机构新闻注册表与 SiC 档案注册表不存在 endpoint/原始内容双重生产路由；混合 Feed 保持待审。
- [ ] Hacker News 与 Lobsters 已从运行时 bundle 排除；Follow Builders X 中央 feed 全量接入，并还原每条记录的原始账号与 canonical X URL，不维护本地账号白名单。
- [ ] Follow Builders X、Blogs、Podcasts 任一中央 feed 断开时，受影响 feed 会告警并保留上一成功快照，其他来源照常投递，workflow 仍成功结束。
- [ ] Frontier 境内 GitHub 快速路径只读取当前参赛名单中的公开仓库，具备服务端凭证、短超时、限流、缓存/条件请求和审计记录。
- [ ] Frontier 直读失败会保持待验证或上一成功值，并通过 rankings 公开任务异步回退；普通页面和浏览器不直接请求 GitHub。
- [ ] 私人邮箱和运营资料不会进入采集器、公开任务或构建产物。
- [ ] `sourceBundleRevision` 只接受部署白名单版本。
- [ ] 批次签名、时间窗、重放、幂等、大小限制、重试与隔离已验证。
- [ ] GitHub Actions 只采集并投递，不持有 worker/LLM 密钥、不调用境内处理；四次有界重试保持同一 `batchId` 与正文。
- [ ] 境内 `vault2077-acquisition-worker.timer` 每五分钟独立消费 inbox；停止、积压、恢复和 quarantine 告警已演练。
- [ ] 首次开放前已完成真实上线基线：SiC 每个 approved 来源至少有最近一条合格内容，Vault 使用最近 30 天真实新闻且未用陈旧来源或演示数据强行填满。
- [ ] bootstrap 与 incremental 可区分；初始化按小批次处理、可幂等补跑，并保留逐来源覆盖、真实原始发布时间和失败证据。
- [ ] `vault_editorial` 稳定处理 information、roadside 与 Vault 事件编排；`sic_editorial` 独立处理 sic，二者共享事实、来源、术语与追溯合同。
- [ ] 两个频道编辑配置拥有独立队列、并发、超时、熔断和故障状态；请求额度为无限但错峰批次不会无界启动模型请求，也不会因 SiC 积压阻塞 Vault。
- [ ] information 滚动保留最近 30 天并验证空增量不清空；roadside/SiC/平台榜逐来源只保留最近成功快照；单条失败不阻塞正常条目，失败来源保留上一成功结果；事件永久保存不可变资讯证据副本。
- [ ] inbox claim token、六次指数退避、成功 30 天/隔离 180 天自动清理及旧 worker 迟到确认拒绝已验证。
- [ ] 采集 workflow 按北京时间白天低频运行，00:00–08:00 不采集；全仓质量门禁在 PR、`main` push 和每日 06:30 独立执行。
- [ ] 每个编辑配置只有一个主处理提供方和一个受控备用；切换条件、幂等重试及提供方/模型/提示版本追溯已验证，不存在随机分发或并行生成后择优。
- [ ] rankings 与 Frontier 的核验、观察、排名和结算没有进入编辑模型。
- [ ] 生产失败不会静默回退到演示数据。

## P0：数据与安全

- [ ] 生产写模型已迁移到 PostgreSQL；文件适配器仅用于开发/预览。
- [ ] schema 迁移、唯一约束、事务、自动备份与实际恢复演练通过。
- [ ] 私人邮箱加密、最小权限访问与保留/删除策略已验证。
- [ ] 管线签名和敏感数据均使用带活动 key ID 的密钥环；新旧重叠、切换、验证和撤旧顺序已演练，旧密文在撤钥前已过保留期或完成重加密。
- [ ] 独立 HTTPS 管理来源使用原生 Passkey；唯一 `owner` 固定为 `lanzhouda@163.com`，公开域名和 Node 端口无法进入后台。
- [ ] 应用校验 WebAuthn challenge、来源、RP ID、签名、用户验证和计数器；重放 ceremony 不能创建会话，本地密码适配器在生产关闭。
- [ ] SSH 一次性引导、恢复码单次消费、凭证撤销、最后凭证保护和全量会话撤销均已在目标环境演练。
- [ ] 后台会话使用 PostgreSQL 可撤销令牌摘要和 `__Host-` 安全 Cookie，空闲/绝对过期与单会话撤销已验证。
- [ ] 后台浏览器写请求通过同源与 CSRF 防护；写操作二次确认并留下不可变审计记录，OPC 发布和奖品状态操作要求最近 5 分钟再认证；后台不存在资讯、事件、SiC 或榜单编辑入口。
- [ ] OPC 草稿增删改、排序、字段校验、并发冲突和发布快照已在目标数据库验证；未登录用户和自动内容管线不能访问该写接口。
- [ ] OPC 订单接口已验证同源与自定义请求头、请求体上限、蜜罐、每日限速、幂等创建、服务端价格和完整协议正文/版本/SHA-256 快照、纸质签约方式白名单，以及联系人和寄送地址加密；用户付款前可下载同一完整协议正文，无效、下架、篡改价格或篡改协议版本的请求不能创建订单。
- [ ] 后台只能按 ADR-0019 状态机处理待付款、到账异常、已付款待合同确认、已到账可履约、退款处理中、已完成、已取消和已退款订单；付款与退款只采信支付宝服务器证据，后台只能提交合同门禁通过或全额退款结论，不能任意写目标状态。查询、合同结论、退款、完成和联系方式导出要求最近五分钟再认证并写入审计。
- [ ] 首次验真到账在同一事务生成唯一付款凭证和唯一 outbox 事件；支付宝回调不等待邮件发送并能在时限内返回，重复付款通知不会生成第二个 outbox。独立 OPC 维护 timer 已真实投递摘要邮件到 `lanzhouda@163.com`，重试复用同一 Message-ID，失败退避、at-least-once 崩溃窗口、非零退出与告警已演练，邮件不包含完整联系方式或恢复凭证。
- [ ] 用户和后台从同一不可变快照查看付款凭证；PNG 下载包含服务、人民币实付金额、双方主体、`https://superones.top`、不含秘密参数的规范路径和“沪ICP备2026003401号-1”，并明确不替代发票。图片不包含恢复令牌、Cookie、完整手机号或完整地址。
- [ ] 后台订单 dossier 贯通服务/完整协议、签约主体、联系信息、支付宝交易、付款凭证、合同结论、退款和审计轨迹；变更使用预期更新时间拒绝陈旧写入，完整联系信息查看要求最近五分钟再认证并单独审计。
- [ ] 未付款取消订单满 90 天、已付款订单完成或退款满 24 个月后的非合同联系方式和寄送地址清除已演练；在线订单及预付款协议快照、付款/退款凭证和审计记录满足约定留存。未来电子签约重新启用前，再单独验收 ADR-0018 的专用私有 OSS、保留锁和下载哈希复核。
- [ ] CSP、HSTS、MIME、防引用泄漏及最小 CORS 等安全头已验证。
- [ ] 生产页面 CSP 使用逐请求 nonce，`script-src` 不含 `unsafe-inline`；动态渲染后的 TTFB、CPU 和并发容量已验证。
- [ ] `/pipeline` 仅本地或认证后台可访问，不在公开导航、sitemap 或索引中。
- [ ] 公网 Nginx 在内部命名空间只放行精确的 `POST /api/internal/acquisition` 与只读 `GET /api/internal/frontier/tasks`；其余 `/api/internal/*`、Node 端口和服务器 IP 均无法从公网访问。
- [ ] Nginx 覆盖客户端转发头，伪造 `X-Forwarded-For` 不能绕过限流或污染审计；边缘和应用限流均已压测。

- [ ] Nginx、Web、采集 worker、Frontier timer 和 OPC 订单维护 timer 的配置已通过语法/单元验证并接入 journal/进程退出告警。
- [ ] 部署、回滚、密钥轮换、备份恢复和事故联系人已演练并留下日期/负责人/结果。
