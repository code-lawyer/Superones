# e签宝价格与低客量替代方案（2026-08-05）

> 核查口径：只使用 e签宝、其他电子签厂商的官方页面/官方商城商品页，以及中国现行法律和司法解释的官方文本。所有价格均为 2026-08-05 查见的公开标价，不等于对 Vault2077 的正式报价。本文不是法律意见。

## 结论先行

**Vault2077 初期没有必要立即购买 e签宝 API 正式套餐，但有必要保留已经完成的 API 适配。**

建议把生产启用拆成两阶段：

1. **0–5 个已签订单/月：用企业 SaaS 页面手工发起。**优先向 e签宝确认 50 份/年 350 元的官方商城套餐是否仍可直接新购；不能购买时，再确认官网 100 份/年 650 元套餐。指定一名运营人员每天处理签约与下载归档。若只有极少数、本地或可邮寄的高价值合同，也可以使用纸质双原件。
2. **暂不购买 API 正式套餐。**先用官方 5 份、7 天体验完成产品验收；代码保留 feature flag 和沙箱适配。等到签约量、响应时效或订单自动化确实需要 API，再凭书面报价启用。

切换 API 的建议门槛是：

- 连续 3 个月达到 **20 份/月**，或手工发起、催签、下载和归档稳定超过 **4 小时/月**；
- 业务必须做到“签完自动开放支付宝付款”、夜间自助签署、回调驱动订单状态，手工衔接已经影响转化或交付；
- 一单多文件、多个模板或补签/拒签量上升，人工差错开始成为主要风险；
- 已取得书面总价，且“版本费 + 最低包量 + 认证/短信 + 存证 + 支持费”的年总成本低于可节省的人工和差错成本。

这不是因为 e签宝单份成本高。Vault2077 当前 21 个服务 SKU 的最低价 1,980 元、中位价 8,800 元、均价约 10,237 元、最高价 29,800 元（本地目录：[opc-selected-skus.ts](../../lib/opc-selected-skus.ts)）。按公开 API 标价 8 元/份计算，电子签成本只占服务价格约 **0.027%–0.404%**。真正需要控制的是未公开固定费、低量包浪费和运营复杂度。

- e签宝官网把企业整体计费概括为“**版本费 + 使用合同份数**”；基础版按份收费，专业版才列出 API 开放。公开流量包价格不能自动理解为 API 全年总价。

- e签宝的 SaaS 扣费通常按“上传的签署文件”计算：一个流程上传两个需签文件可能消耗两份；撤回/拒签返还，过期合同不扣，接收方不扣。API 产品仍以实际订购规则为准。[扣费规则](https://help.esign.cn/h5/detail?id=trtwwn&nameSpace=cs3-dept%252Fexboae)

因此，预算公式应写成：

```text
API 年成本 = F版本/接入固定费 + 8 × 实际计费文件数
             + C实名认证/意愿认证 + C短信 + C额外存证 + C支持/出证
```

`F` 和各附加项当前没有公开、可验证的数值。正式采购前必须让销售在同一份盖章报价或订单中逐项写清。

### 3. 容易漏算的增值项

- 普通电子证据报告/服务证明公开价 100 元/份，纸质 200 元/份；加急电子 200 元/份、纸质 300 元/份。页面说明这是争议后按需申请的人工出证，并非每份合同的必缴签署费。[e签宝出证价格说明](https://help.esign.cn/h5/detail?id=kisnkp51mzppiom0&nameSpace=cs3-dept%2Fexboae)
- 订单可申请发票；500 元以下只能开增值税普通电子发票。公开价格页未写明标价是否含税及税率，不能自行假设。[e签宝发票说明](https://help.esign.cn/h5/detail?id=on5s0d&nameSpace=cs3-dept%2Fexboae)
- 个人 VIP 188 元/年含 30 份及 1 份电子证据报告，但官方明确企业主体不能购买，不能用创始人个人账号替代公司签约主体。[个人 VIP 说明](https://help.esign.cn/h5/detail?id=gcx0182dlpyn3cqt&nameSpace=cs3-dept%2Fza62ha)

## 二、低、中、高签约量成本模型

以下只比较公开的签署平台费，不含人工、研发、税费和询价项；“一份订单 = 一个需签 PDF”是模型假设。实际一单多文件应按文件数放大。

| 年签约量 | 场景 | e签宝手工 SaaS | e签宝 API 公开变量价 | API 对 SaaS 的判断 | 每份订单相对 Vault2077 均价 10,237 元 |
|---:|---|---:|---:|---|---:|
| 20（约 0–2/月） | 低量验证 | 350 元/年（50 份包；余 30 份） | `F + 160 元` | 只有当 `F < 190 元` 且没有其他附加费时，API 平台费才低于该 SaaS 包；现实报价尚未知 | API 变量费约 0.078% |
| 100（约 8/月） | 中量 | 650 元/年 | `F + 800 元` | 即使 `F=0`，API 公开变量价也比 SaaS 多 150 元；API 的价值只能来自自动化 | 同上 |
| 1,000（约 83/月） | 高量 | 5,500 元/年 | `F + 8,000 元` | 即使 `F=0`，API 仍多 2,500 元；但高量下人工和自动化价值可能超过差价 | 同上 |

这张表解释了为什么“客户少不少”不是是否使用 e签宝的唯一问题：

- 是否使用**第三方可靠电子签**，主要取决于远程签约、证据和客户体验；
- 是否使用**API**，主要取决于流程自动化和响应时效；
- 对 Vault2077 的高客单价服务，单份签署费很小，低量阶段优先避免固定费和无效开发/运维投入。

## 三、更便宜的合法路径

### 方案 A：e签宝企业 SaaS 手工发起（首选）

这是当前最均衡的方案：保留企业实名、意愿认证、防篡改、签署记录和合同归档，但不为 API 自动化付固定费。代价是运营人员要手工创建合同、填写客户信息、催签、下载归档，再在后台确认后开放支付。

适用：0–5 个已签订单/月、客户可以接受工作时段处理、合同模板少且一单一个文件。

### 方案 B：纸质双原件

纸质签名/盖章不需要电子签平台费，成本模型为：

```text
纸质年成本 = N ×（打印装订 + 双向寄送 + 人工处理 + 原件保管）
```

本文没有用商业快递报价替这些变量编造金额。法律上，可靠电子签名与手写签名或盖章具有同等效力，并不意味着纸质签署失效；对数量极少、金额高、可等待寄送的订单，纸质仍是可行基线。其缺点是周期长、客户流失、原件保管和邮寄状态管理。

### 方案 C：其他第三方 SaaS，先做采购比价

可确认的低价官方样本：

| 厂商/官方渠道 | 公开价 | 有效期/税费 | 限制 |
|---|---:|---|---|
| 君子签官方阿里云商品 | 475 元/100份、2,300 元/500份、4,500 元/1,000份、8,800 元/2,000份 | 页面未明确有效期、是否含税和税率，需询价 | 公开单价比 e签宝对应档低；切换前仍需核对企业认证、个人意愿认证、自动盖章、API、回调验签、出证和数据导出是否包含 |
| 法大大钉钉渠道官方套餐 | 基础版+40份/半年 350 元；基础版+80份/年 598 元；100份签署包 798 元 | 页面写明半年/一年；税费未明确 | 100份包是否要求已有版本、是否支持公司当前场景需询价；API 不在基础版 |

来源：[君子签阿里云官方商品](https://market.aliyun.com/detail/cmfw033620)、[法大大钉钉渠道套餐说明](https://support.fadada.com/d/1696042469692547074.html)、[法大大官方版本页](https://www.fadada.com/price)。

不建议仅因为每份便宜 1–2 元立即更换。对于 100 份/年，e签宝与上述低价样本的年度差额只有数百元，远小于重写适配、重新法务审核、迁移模板和生产验收的成本。可把它们作为压价和下一年度续费比选的基准。

### 方案 D：自建“订单确认 + OTP + 证据日志”（不是 e签宝等价替代）

法律没有规定企业必须购买 e签宝或任何指定品牌。《电子签名法》第三条允许当事人约定使用或不使用电子签名；第十六条的表述是“电子签名需要第三方认证的”，由依法设立的电子认证服务提供者提供。

《民法典》第四百六十九条规定，可有形展示并可随时调取的数据电文可视为书面形式；第四百九十一条也规定，符合要约条件的互联网商品/服务信息，在用户提交订单成功时可成立合同（当事人另有约定除外）。因此，低风险业务可以经法律审核后设计“展示完整条款—明确同意—短信验证—生成不可变订单版本—付款/履约”的在线订约路径。

但它有三个重要边界：

1. 自建勾选、手写签名图片或短信验证码**不会天然满足**《电子签名法》第十三条的四项可靠电子签名条件，也不能直接宣称与手写签名/盖章同等效力；
2. 最高法合同编通则司法解释明确，仅设置勾选、弹窗，不足以单独证明平台已经履行对重大利害格式条款的提示/说明义务；
3. 发生争议时，需要自行证明主体、真实意愿、条款版本、发送接收、未被篡改、日志完整性和保管系统可靠性。第三方中立保存的电子数据在证据规则中具有更有利的真实性推定条件。

如果采用该路径，至少保留：主体与手机号核验、OTP 结果、条款全文和版本号、每页展示/重要条款单独确认、时间/IP/设备信息、完整 PDF 哈希、发送与下载回执、支付和履约记录、只追加审计日志、异地备份及可复现导出。它的第三方签署平台费可以是 0，但研发、短信、存储、法务和争议举证成本不能视为 0。

法律依据：[《中华人民共和国电子签名法（2019年修正）》](https://www.miit.gov.cn/jgsj/zfs/fl/art/2022/art_e3f623f70c23497e88a941170093446a.html)、[《中华人民共和国民法典》](https://www.court.gov.cn/zixun/xiangqing/233181.html)、[最高法合同编通则司法解释](https://gongbao.court.gov.cn/Details/f4722cf61c92a585f04b2ecd334f5b.html)、[最高法民事诉讼证据规定](https://www.court.gov.cn/zixun/xiangqing/212721.html)。

## 四、为什么第三方电子签仍然有价值

《电子签名法》第十三条要求可靠电子签名同时满足：签名制作数据为签名人专有、签署时仅由本人控制、签后对签名的改动可发现、签后对数据电文内容和形式的改动可发现；第十四条才规定可靠电子签名与手写签名或盖章具有同等法律效力。

采购 e签宝这类平台，本质上不是购买一张“签名图片”，而是购买身份核验、签署意愿、防篡改、数字证书、时间与操作记录、文件归档和按需出证的一体化证据链。低量阶段可以不用 API，但不应把“自建一个签字框”误认为获得了同等能力。

## 五、给 e签宝销售的书面询价清单

在任何生产采购前，要求对方逐项书面回答：

1. Vault2077 当前“企业自身自动盖章 + 自然人手动签 + 托管 H5 + API V3 + 回调 + 文件下载/验签”的**版本年费**是多少？
2. SaaS API 标准版 8 元/份的**最低购买量、有效期和未用份数处理**是什么？是否还需购买专业版或应用扩展包？
3. 个人实名认证、短信意愿认证、企业实名、数字证书、时间戳、基础存证、模板和印章是否已包含？超出后各自单价多少？
4. 一单包含两个 PDF、拒签、撤回、过期、重发、补签分别如何扣费？
5. 沙箱转正式、上线支持、回调白名单、生产故障支持是否另收费？
6. 公开价是否含税，可开什么类型和税率的发票？
7. 普通/加急证据报告、司法鉴定、公证或律师服务是否只在发生争议时按需收费？

## 最终决策

**现在：保留 e签宝技术接入，不开生产 API；用 5 份体验完成验收，然后以 50 或 100 份企业 SaaS 套餐手工运营。**

**以后：达到连续 3 个月 20 份/月、人工超过 4 小时/月，或签署结果必须实时驱动支付宝付款时，拿完整书面报价复算，再开启已经准备好的 API。**

如果正式报价出现较高版本费/最低包量，则继续 SaaS 手工发起，并用君子签、法大大官方报价做年度比价；不建议为了每份节省几元贸然重写供应商适配。纸质合同可作为极少量高价值订单的兜底，自建订单确认只应用于经法律审核的低风险场景，且不得宣传为与可靠电子签名等价。
