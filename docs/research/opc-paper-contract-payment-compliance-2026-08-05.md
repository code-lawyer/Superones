# Vault2077 纸质合同与付款流程合规评估（2026-08-05）

> 核查口径：仅引用全国人大、国务院、最高人民法院、国家市场监督管理总局、国家税务总局、中国人民银行等官方一手来源。本文基于目前描述的业务流程作产品合规分析，不是正式法律意见，也不能替代执业律师结合实际合同文本、服务内容、经营资质和客户类型出具的专项意见。

## 一、结论先行

**页面同时展示“电子签（暂未开放）”和“纸质签”可以上线；纸质合同也可以作为当前唯一可用的签约路径。**法律并不要求经营者必须提供电子签，关键是不得把未开放能力展示成已经可用，也不得误导用户。

《电子签名法》第三条允许民事活动中的当事人约定使用或不使用电子签名，法律、行政法规另有规定的除外；第十四条确认可靠电子签名与手写签名或盖章具有同等法律效力。它没有要求一般民事合同必须同时提供纸质签和电子签。[《电子签名法》第三、十四条（中国人大网）](https://www.npc.gov.cn/zgrdw/npc/xinwen/2019-05/07/content_2086835.htm)

但是，原设想中的完整链路——

> 用户扫码付款 → 商家邮寄纸质合同 → 一周内未收到返签即视为用户不同意 → 退款并扣快递费

**不建议原样上线。**主要问题不是纸质合同，而是“先付款、后判断合同是否成立”的逻辑：

1. 《电子商务法》第四十九条规定，符合要约条件的服务信息在用户提交订单成功时合同成立；更重要的是，经营者不得用格式条款约定“消费者支付价款后合同不成立”，这类内容无效。即使页面写了“以收到纸质合同为准”，付款成功后仍很可能已经成立至少一份在线订单/预付款合同。
2. 如果 Vault2077 面向自然人提供生活消费服务，收款后属于预付款安排，还必须满足书面合同、退款方式和违约责任等要求。若服务属于多次或持续提供的生活消费，2025 年起施行的预付式消费司法解释还可能赋予首次购买消费者付款后七日内请求返还预付款本金的权利。
3. “一周内我们未收到”把快递运输延误风险转嫁给用户；应改为“合同送达后七个自然日内交寄，以承运人首次揽收记录为准”，并允许合理延期。
4. “扣除快递费”没有写明金额、范围和凭证，容易被认定为未充分提示的格式条款、不合理加重消费者责任，或者成为价格不透明。纸质签当前又是唯一可用方案，快递更接近经营者完成签约的必要成本，转嫁给消费者的正当性会更弱。

**首选上线流程：先签后付。**

```text
选择纸质签约
  → 免费提交签约申请（不付款）
  → 展示并下载合同全文、隐私告知和签约步骤
  → 核验自然人/企业签约主体
  → Vault2077 盖章并寄出两份原件
  → 客户在送达后 7 个自然日内签署并交寄一份
  → Vault2077 验收返签原件并发送扫描件
  → 开放企业支付宝付款链接
  → 到款后按合同启动服务并依法开票
```

如果产品必须“先付款后邮寄”，应承认付款成功时在线预付款/订单协议已经成立，把后续纸质文件定位为确认和留档，而不是用“未返签即合同不成立”。七日未返签后应通过约定解除机制终止在线合同并**原路全额退款、不扣快递费**。这是当前最稳妥的降险做法。

## 二、红黄绿风险矩阵

| 等级 | 设计/行为 | 判断与处置 |
|---|---|---|
| 绿 | 页面显示“电子签（暂未开放）”，控件不可点击，并明确当前只能选择纸质签 | 可以上线。不要显示可用价格、承诺确定上线日期或制造“马上可签”的印象 |
| 绿 | 用户先免费提交纸质签约申请，双方完成纸质签署后再付款 | 首选；避免付款后再争论合同是否成立 |
| 绿 | 使用合同主体名下的支付宝企业商户能力收款，付款方看到的商户名称与合同/发票主体一致 | 应采用；不要用员工、股东或其他个人收款码承接公司营业收入 |
| 绿 | 两份原件、统一合同编号、骑缝页/页码、签署日期、物流回执、返签扫描件和原件归档 | 有助于证明文本一致、签署主体和交付链路 |
| 黄 | “送达后七个自然日内交寄，逾期可取消”，并有到期提醒与人工延期 | 可以设计，但应以用户交寄而非商家收到为准；沉默不是同意，只能触发明确约定的取消/解除程序 |
| 黄 | 单独收取固定且明示的“纸质合同寄送服务费” | 只有在用户有真正免费的替代签约方式、费用在付款前单独标价并确认、金额合理且寄送服务确已完成时才较易辩护；当前电子签关闭，不建议采用 |
| 黄 | 未返签时从退款中扣除实际发生的单程快递费 | 即使金额真实，也面临格式条款、公平性和预付款本金返还争议；必须单独显著确认、限定为可举证的实际费用并设置上限。当前建议由 Vault2077 吸收 |
| 红 | 写“付款后合同尚未成立，以收到纸质返签件为合同成立条件” | 与《电子商务法》第四十九条第二款正面冲突，相关格式条款可能无效 |
| 红 | 一周未收到返签件即“视为用户同意”或自动开始服务 | 沉默原则上不能直接作为同意；且形成高争议扣款和履约证据 |
| 红 | 一周未收到即退款，但扣“快递费/手续费/材料费”而不事先给出金额或计算方法 | 价格不透明且可能不合理加重消费者责任，不应上线 |
| 红 | 用个人支付宝收款码收取公司服务款，合同、收款、发票主体不一致 | 带来支付机构商户管理、税务、举证和资金混同风险，应使用真实签约主体的企业商户号 |
| 红 | 地址、身份证照片等在未作隐私告知前一次性强制收集，或把营销同意与寄送捆绑 | 违反最小必要、透明告知和自愿同意要求；不得将履约联系方式用于未经同意的营销 |

## 三、合同何时成立：付款与纸质签署不能相互打架

### 1. 在线提交订单通常已经具有合同意义

《电子商务法》第四十九条规定：经营者发布的信息符合要约条件时，用户选择商品或服务并提交订单成功，合同成立；当事人可以另有约定，但经营者**不得以格式条款约定消费者支付价款后合同不成立**。[《电子商务法》第四十九条（中国人大网）](https://www.npc.gov.cn/WZWSREL3pncmR3L25wYy9sZnp0L3JseXcvMjAxOC0wOC8zMS9jb250ZW50XzIwNjA4MjcuaHRt)

《民法典》第四百九十一条同样规定，互联网服务信息符合要约条件时，对方选择并提交订单成功，合同成立，但是当事人另有约定的除外；采用合同书形式的，原则上自双方签名、盖章或者按指印时成立，一方已履行主要义务且对方接受时也可能成立。[《民法典》第四百九十、四百九十一条（最高人民法院）](https://www.court.gov.cn/zixun/xiangqing/233181.html)

因此，“付款前页面只是意向、付款后仍无任何合同”的说法风险很高。即使主服务合同确实约定以纸质签署为条件，用户付款、商家收款并开始寄送文件，仍会形成至少以下一种关系：

- 在线订单合同；
- 预付款及退款协议；
- 预约合同，即双方负有在约定期限内继续签订主合同的义务；
- 或因一方履行、另一方接受而成立的服务合同。

产品、合同和财务系统必须采用同一套口径，不能在支付页说“购买成功”，退款页又说“合同从未成立”。

### 2. “一周未返签视为不同意”不是最严重的问题，付款在前才是

用户不签字当然可以体现其没有继续纸质签约的意愿；问题在于付款成功后，不能再靠一句“视为不同意”消灭已经形成的在线法律关系。正确处理方式有两种：

- **首选：付款前不形成付费订单。**页面按钮叫“提交纸质签约申请”，明确不收费；纸质合同签完后再创建支付订单。
- **备选：承认在线合同已成立，再按约解除。**约定“用户在文件送达后七个自然日内未交寄，经提醒仍未交寄的，双方同意解除在线订单；Vault2077 在解除后一个工作日内发起原路全额退款”。《民法典》第五百六十五条允许通知中载明一定期限内不履行则合同自动解除；第五百六十六条规定解除后的恢复原状和损失处理。[《民法典》第五百六十五、五百六十六条（最高人民法院）](https://www.court.gov.cn/zixun/xiangqing/233181.html)

《民法典》第一百四十条规定，沉默只有在有法律规定、当事人约定或者符合交易习惯时，才可视为意思表示。因此页面应写“逾期触发取消/解除和退款”，不能写“未回复视为已经同意合同或开始服务”。[《民法典》第一百四十条（最高人民法院）](https://www.court.gov.cn/zixun/xiangqing/233181.html)

期限应从承运人记录的**成功送达次日**开始，用户在第七个自然日 24:00 前完成交寄即视为按时；不要要求在七日内送达 Vault2077，因为运输时间不受用户完全控制。配送异常、法定节假日、不可抗力和用户合理请求应允许人工顺延。

## 四、消费者、预付款和格式条款

### 1. 先区分 B2C 与 B2B

《消费者权益保护法》主要保护“为生活消费需要”购买商品或接受服务的自然人。自然人购买与职业、经营直接相关的企业服务是否属于生活消费，需要结合服务内容判断；以公司名义采购通常属于 B2B，不当然适用消费者特别保护规则。

但即使是 B2B，《民法典》的合同成立、格式条款、公平诚信、代理权限和违约损失规则仍然适用，《电子商务法》第四十九条的付款后不得约定合同不成立也不能忽略。因此建议系统在申请第一步明确选择：

- “我以个人名义签约”；
- “我代表企业/其他组织签约”。

随后使用不同的签约主体字段、合同模板和授权核验流程。

### 2. B2C 预付款必须有书面、透明的退款约定

《消费者权益保护法》第二十六条要求经营者以显著方式提示价款、履行方式、售后和民事责任等重大利害条款；不合理排除消费者权利、免除经营者责任、加重消费者责任的格式条款无效。第五十三条规定，经营者以预收款方式提供商品或服务，应按约提供；未按约提供时，应按消费者要求履行或退回预付款，并承担利息和消费者必须支付的合理费用。[《消费者权益保护法》第二十六、五十三条（中国人大网）](https://www.npc.gov.cn/WZWSREL3pncmR3Ly9ucGMvLy8vLy8vbGZ6dC94ZnpxeWJoZnh6YS8yMDE0LTAxLzAyL2NvbnRlbnRfMTg3MjQ4OC5odG0%3D)

《消费者权益保护法实施条例》第二十二条进一步要求：经营者收取预付款时，应与消费者订立书面合同，约定服务具体内容、价款或费用、预付款退还方式、违约责任等事项；未按约提供服务时应按消费者要求履行或退款。[《消费者权益保护法实施条例》第二十二条（市场监管总局）](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2024/art_0aea188276a44f0baf940ab95ee00e0a.html)

因此，即便采用“先付款后纸签”的备选方案，付款前页面也必须能完整阅览、保存和下载一份在线书面协议，至少写清：

- 服务主体、内容、总价、付款性质；
- 纸质合同寄送和返签步骤；
- 七日起算、提醒、延期、取消和解除规则；
- 退款金额、发起期限、原路退回方式和预计到账提示；
- 服务启动条件；
- 客服、投诉和争议解决渠道。

### 3. 多次或持续服务还可能适用“付款后七日无理由退款”

最高人民法院法释〔2025〕4号适用于零售、住宿、餐饮、健身、培训、养老、旅游等生活消费领域中，经营者收取预付款后**多次或者持续**向消费者提供商品或服务的纠纷。其第十四条规定，消费者自付款之日起七日内请求返还预付款本金的，法院原则上予以支持，但消费者此前已从该经营者或其他经营者获得过相同商品或服务等例外除外；第十五条允许当事人依法主张已经支付的合理费用等损失。[预付式消费司法解释全文（最高人民法院公报）](https://gongbao.court.gov.cn/Details/415add6e9c15736f2fbd871bdb1538.html)

Vault2077 如果是一锤子交付的企业咨询项目，未必落入该解释第一条的适用范围；如果面向自然人、按期或多次持续交付服务，则适用概率明显提高。在适用该解释的情况下，第十四条强调“返还预付款本金”，七日内直接扣快递费的抗辩空间有限，至少会产生争议。不能把第十五条的“合理费用”理解成经营者可以无条件、自动从任何七日退款中扣费。

另需区分：消费者法上的网购“七日无理由退货”主要针对网络销售的**商品**，并不是所有在线服务天然都有七日无理由解除权。[《消费者权益保护法》第二十五条（中国人大网）](https://www.npc.gov.cn/zgrdw/npc/xinwen/2013-10/26/content_1811773.htm) 本方案中的七日，应被明确设计为双方约定的纸质签约期限；若落入前述预付式消费解释，则另有法定的七日退款规则。

### 4. 仅靠勾选或弹窗不足以证明重大条款已经有效提示

《民法典》第四百九十六、四百九十七条要求格式条款提供方公平确定权利义务，对重大利害条款作合理提示和说明；不合理免除或减轻自身责任、加重对方责任、限制或排除对方主要权利的条款可能不成为合同内容或无效。[《民法典》第四百九十六至四百九十八条（最高人民法院公报）](https://gongbao.court.gov.cn/Details/dfe439fb9450f0525bd7e7b50a6242.html)

最高人民法院合同编通则司法解释第十条明确：在线合同提供方仅以设置了勾选、弹窗为由主张已履行提示或说明义务，法院不予支持；提供方还要证明明显标识足以引起注意，并对法律后果作了通常能够理解的说明。[合同编通则司法解释第十条（最高人民法院公报）](https://gongbao.court.gov.cn/Details/f4722cf61c92a585f04b2ecd334f5b.html)

因此，“逾期取消、退款扣费、服务启动、争议解决”等内容应在付款按钮前以短句摘要、加粗金额、独立确认和可下载全文共同呈现，并保存用户实际看到的条款版本和确认记录。

## 五、快递费：什么情况下可以扣，什么情况下不应扣

### 当前推荐：不扣，列入获客和签约成本

纸质签当前是唯一可用签约方式，经营者为了完成自己要求的签约形式而寄出合同，快递费更像履约准备或缔约成本。Vault2077 客单价相较一笔单程快递费很高，吸收该成本可以显著降低格式条款、价格投诉和退款争议，商业上也更划算。

### 如果以后一定要收费，至少同时满足以下条件

1. 用户存在真正可用且免费的电子签路径，纸质寄送是用户主动选择的增值服务；
2. 付款前单独标示“纸质合同寄送服务费 ¥X”，不得在退款时才出现；
3. 单独确认，不与主服务购买或隐私授权捆绑；
4. 金额与实际单程寄送成本合理对应，不包含内部人工、获客、支付手续费或惩罚性加价；
5. 明确何时视为寄送服务完成，未寄出、错寄、无法送达或商家原因取消时全额退；
6. 保留承运人账单和运单，能证明金额；
7. 合同、订单、支付页和发票项目保持一致。

《民法典》第五百八十四、五百八十五条允许赔偿可预见的实际违约损失以及约定违约金，但过高违约金可以被调减；这不能替代消费者格式条款的公平和显著提示要求。[《民法典》第五百八十四、五百八十五条（最高人民法院）](https://www.court.gov.cn/zixun/xiangqing/233181.html)

不要使用以下表述：

- “扣除快递费后退款”；
- “扣除相关费用”；
- “公司有权决定应扣金额”；
- “逾期不签视为违约，概不退款”；
- “最终解释权归 Vault2077 所有”。

## 六、地址、联系方式与个人信息

收件人姓名、手机号和详细地址属于个人信息。为了寄送用户主动申请的纸质合同，在必要范围内处理这些信息，可以《个人信息保护法》第十三条第二项“订立、履行个人作为一方当事人的合同所必需”为基础，不必机械地把所有处理都设计为勾选同意；但仍必须在收集前完成第十七条规定的显著、清晰告知，并遵守第六条最小必要和第十九条最短保存期限。[《个人信息保护法》第十三至十九条（中国人大网）](https://www.npc.gov.cn/WZWSREL25wYy9jMi9jMzA4MzQvMjAyMTA4L3QyMDIxMDgyMF8zMTMwODguaHRtbD9yZWY9aW1i)

收集页应直接说明：

- 处理者的企业全称和联系方式；
- 收集收件人姓名、手机号、地址的目的为纸质合同寄送、物流查询、返签联系和争议处理；
- 必填与选填字段；
- 保存期限或明确的确定方法；
- 查询、更正、删除和联系客服的路径；
- 将必要收件信息提供给所选快递公司的事实。

委托快递企业处理收件信息时，应依《个人信息保护法》第二十一条在服务协议中约定处理目的、期限、方式、信息种类、保护措施和双方义务，并监督受托方；不要把无关的身份证号、合同金额、服务详情写在快递面单或提供给承运人。[《个人信息保护法》第十九至二十一条（市场监管总局转载全文）](https://www.samr.gov.cn/wljys/gzzd/art/2023/art_3ef1e889c1e644d4b65b5f5c7f432386.html)

具体控制建议：

- 只收寄送所需姓名、手机和地址；身份证照片默认不收；
- 如高风险服务确需核验身份证，另作必要性评估，采用遮罩、水印、权限隔离和更短保存期；
- 地址自动填充不等于营销同意；合同催签属于当前交易联系，营销短信/电话必须另有自愿同意并可随时取消；
- 客服后台默认遮罩手机号和详细门牌，按角色开放查看；
- 导出、修改、重寄、删除均写入审计日志。

## 七、自然人与企业签署：主体和证据必须对得上

### 1. 自然人签约

至少保存：合同编号及版本、签约人姓名、可靠联系方式、手写签名/按指印、签署日期、物流签收与返寄记录、双方完整原件或扫描件、付款与退款记录、通知和客服沟通记录。

不要仅靠“收件人姓名等于签约人”证明身份。可根据服务金额和风险，采用视频/人工核验、手机号验证或现场证件比对，但应坚持最小必要。合同每页连续编号，关键价格、服务范围、退款和违约条款宜由用户签名或简签确认，任何手写修改应由双方在修改处签名/盖章。

### 2. 企业/组织签约

应核对企业名称、统一社会信用代码、签约主体存续状态、法定代表人或经办人职务，并要求加盖公司公章或合同专用章；非登记法定代表人签署时，取得载明代理事项、权限和期限的授权委托书。合同、支付宝收款商户、发票抬头和实际履约主体应保持一致。

《民法典》第六十一条规定法定代表人以法人名义从事民事活动的法律后果由法人承受；第一百六十五条规定书面授权委托书应载明代理事项、权限和期限；第一百七十条规定工作人员在职权范围内以组织名义实施的行为对组织发生效力。[《民法典》第六十一、一百六十五、一百七十条（最高人民法院）](https://www.court.gov.cn/zixun/xiangqing/233181.html)

最高人民法院合同编通则司法解释第二十二条进一步说明，合同是否对法人发生效力不只取决于印章真假，还要看签署人是否有权限；仅盖章或仅签字在满足权限证明时也可能有效。[合同编通则司法解释第二十二条（最高人民法院公报）](https://gongbao.court.gov.cn/Details/f4722cf61c92a585f04b2ecd334f5b.html) 实务上仍建议“企业印章 + 有权签署人签名 + 授权链”三者尽量齐全。

### 3. 证据链

至少归档：

- 用户提交申请时的页面快照、合同摘要、全文 PDF、版本号和时间；
- 用户的签约方式选择、重大条款独立确认、IP/设备和短信验证结果；
- 合同生成、打印、用印审批、寄出、签收、提醒、返寄、验收时间；
- 原始运单与承运人轨迹，不只保存截图；
- 双方签署完成的完整扫描件及文件哈希；
- 支付宝商户订单号、金额、到账、退款请求、退款结果；
- 发票开具及红冲记录；
- 原件存放位置、借阅和销毁记录。

最高人民法院民事证据规定第十四条将电子交易记录、通信记录和登录日志等列入电子数据；第九十三条要求从系统可靠性、完整保存、正常业务形成等方面判断真实性；由中立第三方平台提供或确认、在正常业务中形成、以档案方式保管的电子数据，在符合条件时更有利于真实性认定。[最高人民法院民事诉讼证据规定](https://www.court.gov.cn/zixun/xiangqing/212721.html)

## 八、支付宝收款、退款与发票

### 1. 收款

应使用与合同签约方一致的公司支付宝特约商户能力创建有订单号的支付交易，不使用个人静态收款码。国务院《非银行支付机构监督管理条例》将特约商户定义为与支付机构签订支付服务协议、由支付机构完成资金结算的经营主体，并要求支付机构自行完成商户尽职调查、协议签订和持续风险监测。[《非银行支付机构监督管理条例》第十二、二十二条（国家行政法规库）](https://xzfg.moj.gov.cn/mobile/law/detail?LawID=1696)

支付页和支付结果页应显示：合同/订单编号、收款主体、服务名称、金额、付款性质、客服和退款规则。支付宝交易号必须与内部订单和合同编号双向关联。

### 2. 退款

推荐规则：

- 解除/取消成立后一个工作日内通过原支付交易发起原路退款；
- 页面区分“已发起退款”和“银行/支付宝已入账”，如实提示到账时间；
- 退款失败进入人工队列，不能静默结束；
- 不用线下转账替代原路退款，除非原路客观失败且完成收款人身份和账户核验；
- 保存退款请求、支付宝返回结果和用户通知回执。

### 3. 发票

《电子商务法》第十四条要求电子商务经营者依法出具纸质或电子发票等购货凭证、服务单据；《消费者权益保护法》第二十二条也规定消费者索要发票时经营者必须出具。[《电子商务法》第十四条（中国人大网）](https://www.npc.gov.cn/WZWSREL3pncmR3L25wYy9sZnp0L3JseXcvMjAxOC0wOC8zMS9jb250ZW50XzIwNjA4MjcuaHRt) [《消费者权益保护法》第二十二条（中国人大网）](https://www.npc.gov.cn/WZWSREL3pncmR3Ly9ucGMvLy8vLy8vbGZ6dC94ZnpxeWJoZnh6YS8yMDE0LTAxLzAyL2NvbnRlbnRfMTg3MjQ4OC5odG0%3D)

国家税务总局现行发票管理办法实施细则要求在发生经营业务确认营业收入时开票；开具电子发票后发生销售退回、应税服务中止或销售折让，应按规定开具红字发票。[《发票管理办法实施细则》第二十四、二十七条（国家税务总局）](https://fgk.chinatax.gov.cn/zcfgk/c100011/c5221006/5221006/files/26eb7c984dcaa45695231408ca4dfb_1.0.pdf)

因此，不要以“以后还会退款”为由拒绝用户依法索票；如果已开票后全额或部分退款，财务系统应同步按适用规则红冲或调整，退款金额、红字发票和会计记录保持一致。

## 九、推荐的可上线产品流程

### 方案 A：先签后付（建议采用）

1. **方式选择页**
   - 电子签卡片：不可点击，显示“暂未开放”；
   - 纸质签卡片：显示预计寄送、返签、付款和服务启动步骤；
   - 不把电子签显示为促销诱饵或默认已选项。
2. **展示合同**
   - 根据个人/企业身份生成合同；
   - 可在线完整阅读并下载 PDF；
   - 对价格、服务范围、履行期限、终止/退款、责任限制和争议解决作显著摘要。
3. **免费提交申请**
   - 按钮明确为“提交纸质签约申请（暂不付款）”；
   - 收取最少的联系方式和地址并显示隐私告知；
   - 生成申请编号，不生成“已购买/支付成功”状态。
4. **人工核验与寄送**
   - 核验签约主体和授权；
   - Vault2077 在两份合同上盖章并登记编号；
   - 免费寄出，提供物流查询。
5. **用户返签**
   - 期限为送达次日起七个自然日内交寄，以首次揽收为准；
   - 到期前 48 小时提醒一次；支持客服合理延期；
   - 未交寄则关闭申请，不收费、不形成退款。
6. **验收与付款**
   - 收到返签原件后检查主体、签章、修改和完整性；
   - 向用户发送双方签署扫描件和企业支付宝付款链接；
   - 合同可以约定“双方签署时成立，到款后开始履行”，将成立与履行条件分开。
7. **履约与开票**
   - 到款、支付回调和人工复核一致后启动服务；
   - 依法开票，并归档合同、支付和交付记录。

### 方案 B：业务坚持先付款（仅作为降险备选）

1. 付款前展示并允许下载完整的《在线订单及纸质确认协议》；
2. 明确“付款成功即在线订单协议成立”，不能写付款后合同不成立；
3. 将款项称为“服务预付款”，清楚列出主服务、纸质确认、退款和服务启动规则；
4. 用户在送达次日起七个自然日内交寄；到期前提醒并提供延期；
5. 用户未交寄时，按协议解除在线订单，不得用“沉默视为同意”；
6. 解除后一个工作日内发起原路**全额**退款，Vault2077 吸收合同打印和单程快递费；
7. 在纸质合同完成前不开始实质服务、不消耗用户预付款；
8. 如果已开票，按税务规则同步红冲。

方案 B 仍然比方案 A 复杂：系统必须管理在线协议和纸质合同两套文本的关系、解除通知、退款和发票状态。低客户量阶段没有必要为了提前几天占用资金承担这种合规和运营复杂度。

## 十一、上线门禁清单

- [ ] 电子签卡片明确“暂未开放”，不可选择、不可支付；
- [ ] 纸质路径首选“先签后付”；
- [ ] 页面、合同、订单、支付宝和发票主体一致；
- [ ] 明确个人/B2B 签约主体分流；
- [ ] 合同全文付款前可阅读、下载并按版本留档；
- [ ] 重大条款不仅勾选，还以可理解摘要和明显字体提示；
- [ ] 七日按“送达次日—用户交寄”计算，不按 Vault2077 收件时间；
- [ ] 当前不向用户扣合同打印或快递费；
- [ ] 隐私告知覆盖地址、电话、快递委托和保存期限；
- [ ] 只使用企业支付宝商户订单，不使用个人收款码；
- [ ] 未签署且未付款不启动服务；先付款备选路径在纸签前不消耗预付款；
- [ ] 退款有原路、时限、失败重试、通知和审计日志；
- [ ] 发票和退款红冲状态联动；
- [ ] 两份合同原件、授权、运单、签收、返寄、扫描件和付款记录可关联检索；
- [ ] 正式上线前由中国执业律师审阅实际合同、页面文案和服务资质。

## 十二、最终建议

**可以保留两个签约方式，但把“电子签”做成清晰的未开放状态，而不是可点击入口；纸质签约采用“免费申请—双方签署—企业支付宝付款—开始服务”。**

不建议初期使用“先扫码付款、七天未返签退款扣快递费”。它把合同成立、预付款、格式条款、物流、退款和发票问题全部叠在一起，而一笔快递费相对 Vault2077 的订单金额很小。吸收快递费、把付款放到返签之后，既更符合《电子商务法》第四十九条，也能显著减少消费投诉和证据争议。
