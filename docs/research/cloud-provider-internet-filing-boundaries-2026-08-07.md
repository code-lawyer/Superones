# 中国主流云厂商互联网备案与许可证服务边界（2026-08-07）

## 1. 结论

“基础上线事项云厂商基本自带”这句话只对了一半：

- **网站 ICP 备案和原生 APP 备案**：三家都提供接入商备案系统、前置校验、接入商初审和提交管局的法定通道，基础服务通常不另收费；但客户仍要准备真实主体、域名、服务器、产品和负责人材料，并亲自完成实人/短信核验及最终确认。
- **小程序、快应用备案**：通常应经对应运行平台办理，不因为后端在某家云上就统一交给云厂商。
- **公安联网备案**：三家都有指南，部分网站备案订单还能同步数据并生成“数据码”，但主办者仍要登录全国互联网安全管理服务平台完成申请；APP 通常不能靠网站数据码完成。
- **ICP/EDI 许可证**：不是云资源默认附带。腾讯云和华为云核心文档明确要求客户自行向属地通信管理局办理；阿里云另有付费咨询代理产品。三家云市场也都有第三方服务商出售代办，但这属于市场商家的人工服务，不是购买云服务器后自动包含的能力，也不是云厂商或主管机关保证下证。

因此，OPC 如果只销售“替客户在云厂商备案控制台填表”，差异化很弱；如果承担**跨云迁移、产品/收入模式判断、多产品字段底稿、内容与主体一致性检查、公安备案续办、ICP/EDI 准入差距和持续维护**，仍有明确价值。

## 3. 官方证据

### 3.1 阿里云

阿里云将备案分为免费基础服务和收费增值服务。基础系统支持网站、APP 的申请、变更、注销和认领；收费项包括备案管家、备案助手和迁移服务。备案管家覆盖备案引导、资料收集、材料加工、审核、资料填写与代提交，但服务以相关部门确认受理为重要边界。[阿里云备案产品简介](https://help.aliyun.com/zh/icp-filing/product-overview/overview)、[阿里云备案计费](https://help.aliyun.com/zh/icp-filing/product-overview/product-billing)、[备案管家服务范围](https://help.aliyun.com/zh/icp-filing/value-added-icp-service/product-or-service-range)

使用阿里云备案的前提是实际接入阿里云中国内地节点。申请人需要注册/实名认证账号、准备域名和服务器，上传材料，完成负责人真实性核验与工信部短信核验；阿里云初审后再提交管局。负责人异地时可以收到核验链接，但仍须本人上传证件并完成人脸核验。[阿里云 ICP 备案流程](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/icp-filing-application-overview)、[真实性核验 FAQ](https://help.aliyun.com/zh/icp-filing/basic-icp-service/support/upload-data-and-authenticity-check-the-faq)

原生 APP 使用阿里云作为后台接入商时，可以通过阿里云备案；备案智能助理能从安装包辅助检测包名、签名、公钥等信息，但主办者仍须提供完整产品资料并完成核验。[阿里云 APP 备案快速入门](https://help.aliyun.com/zh/icp-filing/basic-icp-service/getting-started/quick-sta-rt-for-icp-filing-for-personal-app)

公安联网备案并不由阿里云基础备案系统自动完成。网站备案订单可在授权后生成公安备案数据码，减少重复填写；该能力目前不支持 APP，APP 主办者仍须前往公安平台自行申请。阿里云另售“公安备案管家”人工服务。[阿里云公安备案数据码](https://help.aliyun.com/zh/icp-filing/basic-icp-service/using-data-code-for-public-security-network-filing)、[阿里云公安联网备案快速入门](https://help.aliyun.com/zh/icp-filing/basic-icp-service/quick-start-for-public-security-network-filing-for-personal-websites)

阿里云另有 ICP、EDI 付费咨询代理产品，由阿里云与合作方提供材料收集、加工、审核、代提交和进度跟踪；协议明确不保证申请必然受理或成功。ICP 初次申请产品的公开说明也把服务与最终行政决定分开。[阿里云 ICP 咨询代理](https://help.aliyun.com/zh/icp-filing/qualification-license-service/alibaba-cloud-commercial-internet-content-provider-consulting-representation)、[阿里云 EDI 咨询代理协议](https://help.aliyun.com/zh/icp-filing/qualification-license-service/alibaba-cloud-edi-license-consulting-proxy-service-agreement)

### 3.2 腾讯云

腾讯云 ICP 备案服务不收费，但客户需购买符合备案条件的中国内地云资源；备案流程仍要求客户准备域名、资源和属地材料，填写资料，经腾讯云审核、工信部短信核验和管局审核。[腾讯云备案定价](https://cloud.tencent.com/document/product/243/18793)、[腾讯云快速备案网站或 APP](https://cloud.tencent.com/document/product/243/39038)

腾讯云当前规则允许一个企业主体在同一订单最多新增十个网站或十个 APP 服务，但一个账号同时只能有一个在办订单，且各省可能另有限制。这说明云厂商提供的是批量提交入口，不是替主办者完成产品信息治理。[腾讯云备案限制](https://cloud.tencent.com/document/product/243/18911)

腾讯云为公安联网备案提供操作指南，并允许网站 ICP 备案时选择同步信息、后续通过数据码减少填写；申请仍在全国互联网安全管理服务平台完成。腾讯云核心备案文档同时明确，公安备案和经营性备案需客户自行向相关部门办理。[腾讯云公安联网备案指引](https://cloud.tencent.com/document/api/243/19142)、[腾讯云备案场景](https://cloud.tencent.com/document/product/243/18910)

对 ICP/EDI 许可证，腾讯云明确表示“目前无法提供经营性备案方面的协助”，客户需自行联系省通信管理局；腾讯云能做的是在客户已有非经营性备案订单后提供备案合同和接入单位 IDC 许可证等接入材料。腾讯云市场虽有第三方付费代办商品，但其交付主体和内容是市场服务商，不应表述为腾讯云基础产品自带。[腾讯云经营性备案 FAQ](https://cloud.tencent.com/document/product/243/19624)、[腾讯云市场 ICP/EDI 代办示例](https://market.cloud.tencent.com/products/22579)

### 3.3 华为云

使用华为云中国大陆节点资源时，客户通过华为云 ICP 代备案系统申报网站和 APP；需准备账号、域名、云资源和材料，并经过华为云初审、短信核验和管局审核。APP 由华为云提供接入服务时可在华为云备案；小程序和快应用则由其运行平台代为履行备案手续。[华为云备案流程](https://support.huaweicloud.com/usermanual-icp/zh-cn_topic_0000002127712329.html)、[华为云 APP 备案 FAQ](https://support.huaweicloud.com/icp_faq/icp_05_0241.html)

华为云可在网站 ICP 备案时，经客户授权同步信息并生成公安备案数据码，但 APP 和其他备案类型不支持该数据码；华为云同时明确公安联网备案由主办者自行在公安平台完成。[华为云公安备案数据码](https://support.huaweicloud.com/tg-icp/zh-cn_topic_0000002545298453.html)、[华为云备案成功后 FAQ](https://support.huaweicloud.com/icp_faq/icp_05_0069.html)

华为云核心文档要求经营性 ICP 许可证由客户自行到属地通信管理部门办理；如管局要求接入商资质材料，客户可提交工单完成身份核实后获取。华为云云商店存在 ICP/EDI 第三方人工代办，但并非华为云服务器默认权益。[华为云 ICP 快速入门](https://support.huaweicloud.com/qs-icp/icp_07_0002.html)、[华为云公安和经营性备案指南](https://support.huaweicloud.com/tg-icp/%E5%A4%87%E6%A1%88%E6%88%90%E5%8A%9F%E5%90%8E-pdf.pdf)、[华为云云商店 ICP/EDI 商品示例](https://marketplace.huaweicloud.com/contents/53fcc80c-1676-49aa-8a04-d77357315174)

## 4. 对 OPC 服务优先级的修正

### 4.1 不宜作为高毛利独立服务

1. 单纯代填网站 ICP 备案；
2. 单纯代填 APP 备案；
3. 把接入商本应免费提供的备案通道重新包装成“官方代办”；
4. 仅复述云厂商已有操作指南的公安备案服务。

这类工作适合作为低价引流、云部署项目的附赠项或更大合规项目的组成部分。阿里云已经直接销售备案管家，OPC 在同一云、单一网站、材料齐全场景很难形成明显优势。

### 4.2 仍有差异化的服务

1. **上线适用性筛查**：区分无需许可证的自营销售、需要 ICP 的经营性信息服务、需要 EDI 的第三方交易平台，以及行业前置审批。
2. **多产品备案运营**：为同一主体的多网站、APP、小程序建立可复用主数据、逐产品技术字段和变更台账；云厂商只审核本次订单，不替企业治理全部产品组合。
3. **跨云/换接入商迁移**：处理接入备案、取消接入、域名和主体一致性、不中断迁移计划及多云信息同步。
4. **公安备案闭环**：从 ICP 结果衔接公安平台、补齐无法同步的字段、检查备案号展示和后续变更，而不是只提供链接。
5. **ICP/EDI 许可准入与材料工程**：先做业务分类和差距评估，再处理真实人员、股权、社保、产品能力、技术与安全材料；许可证的商业价值仍明显高于基础备案。
6. **持证后维护**：年报、变更、续期、产品新增和持证主体/实际业务一致性复核；这是云厂商基础备案通道通常不覆盖的持续责任。

### 4.3 建议销售话术

不应说：

> 我们替你办理云厂商自带的备案。

更准确的说法是：

> 云厂商提供免费的法定备案通道和接入审核；我们负责判断你的产品需要什么、把跨云和多产品材料一次整理正确、陪同完成核验与补正，并把 ICP、公安备案、许可申请和上线后的持续义务串成闭环。客户仍是申请/备案主体，需亲自完成实名核验、签章和真实性确认。

## 5. 研究边界

- 本文核验日期为 2026-08-07，云厂商产品、可备案资源、订单数量和增值服务价格会变化，实际下单前应重新核验。
- 云市场/云商店链接只证明平台上存在第三方付费服务，不代表云厂商为商家的法律判断、交付承诺或取证结果背书。
- “代备案系统”是接入服务商依法提供的提交与核验通道，不等于客户可以把材料真实性、实名核验和持续合规责任转移给接入商或 OPC。
- 本文是产品研究，不构成对个案是否需要 ICP、EDI 或其他行业许可的法律意见。
