# OPC公司启动包

> **页面状态：建议试行版（2026-07-26）**  
> 本页价格用于第一阶段产品测试。政府规费、第三方软件或平台费用、持牌专业机构费用及超出标准范围的工作均单独列示。服务开始前以订单确认页和服务协议为准。

## 1. 服务卡片

| 项目 | 内容 |
|---|---|
| 一句话结果 | 把“准备开公司”推进到可以签约、收款、开票和规范留档。 |
| 适合谁 | 首次设立中国大陆经营主体，或公司已注册但银行、税务、合同和经营配置尚未完成的个人创业者。 |
| 核心成果 | 一个完成设立或补齐启动配置的经营主体；对公账户、税务与发票办理路线；基础合同与公私资金隔离规则 |
| 标准周期 | 15—25个工作日 |
| 建议试行标准价 | **¥8,980** |
| 服务方式 | 一次性启动总包；以远程协作为主 |
| 开始方式 | 先完成10分钟适配问卷，再确认范围与订单 |

## 2. 你现在可能遇到的问题

- 不知道有限公司、个体户或其他主体如何选择
- 注册资本、经营范围和地址方案拿不准
- 公司注册后仍不会收款、开票和报销
- 个人资金、公司资金和文件混在一起
- 担心遗漏受益所有人备案、年报或首年税务事项

## 3. 完成后，你将获得什么

- 一个完成设立或补齐启动配置的经营主体
- 对公账户、税务与发票办理路线
- 基础合同与公私资金隔离规则
- 证照、印章、账号和文件的企业档案
- 首年财税与合规日历

## 4. 标准服务内容

| 阶段 | 我们完成的工作 | 责任方式 |
|---|---|---|
| 启动诊断 | 确认主体类型、地区、业务、准入和股权安排 | 我们主导；专家按需复核 |
| 设立设计 | 名称、经营范围、注册资本、地址和人员方案 | 我们完成，客户决策 |
| 主体办理 | 准备工商材料、协助提交、跟踪并处理补正 | 合作机构/客户办理，我们协调 |
| 经营配置 | 印章、银行、税务、发票、收款和受益所有人备案清单 | 我们协调，客户配合实名或到场 |
| 基础治理 | 公私账户、报销、合同、档案和账号规则 | 我们完成 |
| 最终交付 | 资料归档、操作讲解和首年日历 | 我们完成 |

责任方式说明：

- **我们完成**：由OPC服务平台在约定范围内直接交付。
- **我们协调**：由客户、平台、主管机关或合作机构实际办理，我们负责材料、进度和问题协调。
- **专家复核/办理**：依法或依专业标准应由律师、会计师、税务师、代理机构等完成的，由相应专业主体另行确认并交付。
- **客户决策/配合**：需要本人实名、签字、到场、授权或作出经营决定的事项，必须由客户完成。

## 6. 用户需要提交的材料

### 开始前必须提交

- 创始人及股东身份证明与联系方式
- 拟经营业务、地区和公司名称
- 拟任法定代表人、董事、监事等信息
- 注册地址材料或地址需求

### 特定情况下提交

- 行业许可或前置审批材料
- 境外股东或特殊身份材料
- 知识产权出资资料
- 银行要求的经营证明

### 用户需要投入

填写问卷约30分钟；完成实名、签字和方案确认；银行等环节可能需要到场1次。

所有材料通过指定入口提交。涉及身份证件、客户数据、商业秘密或账号权限时，仅收集完成本项目所必需的信息，并按项目权限和保留规则处理。

## 7. 服务流程

1. **适配判断**：完成问卷，识别是否适合标准包。
2. **订单确认**：确认服务范围、价格、第三方费用和预计周期。
3. **材料接收**：按清单提交完整、真实、可用的材料。
4. **方案确认**：客户确认关键选择和不包含事项。
5. **执行与周报**：按阶段推进；需要客户决定的事项集中提出。
6. **交付验收**：按交付清单检查文件、配置、账号和状态。
7. **售后答疑**：在约定期限内处理交付范围内的问题。

## 8. 周期说明

- **标准周期**：15—25个工作日。
- **起算条件**：自完整材料收到、关键方案确认且首期款到账后的下一个工作日起算。
- 外部主管机关、银行、平台、第三方供应商审核时间，以及客户补充材料或延迟确认的时间，不计入我们承诺的制作周期。
- 客户改变已确认方案、增加范围或未按时反馈时，周期根据变更单顺延。

## 14. 常见问题

### 可以直接购买吗？

先完成适配问卷。标准情形可以直接确认订单；命中升级条件时，先安排总顾问或专业人员判断。

### 为什么有些事项写“协助”而不是“代办”？

因为实名、签字、到场、审批和专业执业等事项存在法定或平台责任主体。页面会明确谁制作、谁提交、谁决定、谁出具正式成果。

### 第三方费用怎么控制？

在订单确认页单列预计费用和支付对象。未经客户确认，不代客户产生新的第三方付费。

### 能保证结果吗？

保证完成约定工作和交付物，不保证主管机关、银行、平台、交易对方或市场作出特定结果。
